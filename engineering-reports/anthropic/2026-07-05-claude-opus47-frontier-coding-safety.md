# Claude Opus 4.7 — 前沿编码与差异化安全策略

**发布日期：** 2026年4月16日
**来源：** https://www.anthropic.com/news/claude-opus-4-7
**工程范式：** 谨慎前沿 — 能力递增与安全堆栈同步演化

## 设计哲学

Claude Opus 4.7 的设计哲学根植于 Anthropic 在 **Project Glasswing** 框架下的战略选择：在能力提升的同时，对高风险领域（网络安全）进行**差异化能力压制**（differential capability reduction），而非单纯通过后置安全层来管控风险。

核心逻辑：
- **能力不能无条件扩张。** Opus 4.7 的编码和视觉能力显著超越 Opus 4.6，但其网络安全能力被人为训练至低于 Mythos Preview 的水平。
- **安全是训练时约束，而非推理时过滤。** 通过训练过程直接降低模型在禁止/高风险网络安全任务上的能力，而非仅仅依赖推理时的内容过滤。
- **可信研究者例外。** Cyber Verification Program 为合法安全研究人员提供受控访问，形成"能力压制 + 受控豁免"的双轨机制。
- **渐进部署。** Opus 4.7 是 Anthropic 计划中首个部署这些新安全机制的模型，为后续 Mythos 级别模型的广泛发布积累实战经验。

这与传统"先释放全部能力，再通过 guardrail 兜底"的范式形成根本性分歧。Anthropic 选择在能力堆栈中嵌入安全约束，而非将其作为附加层。

## 关键架构决策

### 新 Tokenizer（1.0–1.35×）

Opus 4.7 采用更新后的 tokenizer，改善了文本处理效率，但代价是相同输入可能映射为 **1.0–1.35 倍**的 token 数（因内容类型而异）。这是架构层的 tradeoff：更精细的 token 化粒度换取更好的理解质量，但直接增加 API 调用成本。用户在迁移时需重新测算 token 预算。

### xhigh Effort Level

新增 **xhigh**（extra high）effort 级别，位于之前的 high 和 max 之间。允许用户在推理深度与延迟之间做更精细的调节。Claude Code 默认 effort 已提升至 xhigh。官方推荐从 high 或 xhigh 开始调优。

高 effort 级别下模型倾向于在后轮 agent 任务中产出更多 output tokens（更多思考），因此 token 消耗会系统性增加。这是"思考越多越可靠"的架构取舍。

### 差异化安全策略：Cyber Verification Program

Anthropic 在 Opus 4.7 上实验了一种全新的安全管理模式：

1. **训练级压制**：在训练过程中主动降低模型在危险网络安全任务（如漏洞利用开发、大规模攻击工具编写）上的能力。Opus 4.7 的 CyberGym 得分虽然高于 Opus 4.6（73.8 vs 66.6，注意 4.6 的分数已修订），但远低于 Mythos Preview 的完整能力水平。
2. **推理时阻断**：自动检测并拦截指示被禁止或高风险网络安全用途的请求。这是模型内置的检测机制，而非独立的过滤系统。
3. **受控豁免通道**：Cyber Verification Program 为从事漏洞研究、渗透测试和红队演练的合法安全研究人员提供访问权限，形成"制度性后门"。

### 自动检测/阻断高风险网络安全请求

模型内置了请求分类机制，能够实时判断用户意图是否属于禁止或高风险的网络安全用途。这是第一个将此类保护直接集成到模型推理过程中的 Claude 模型。Anthropic 将根据此模型的真实部署经验，迭代防御策略并最终用于 Mythos 级别模型的广泛发布。

### Vision 能力增强

- 最大支持 **2,576 像素长边**（约 3.75 百万像素），是此前 Claude 模型的 **3 倍以上**。
- 这是模型级变化而非 API 参数，用户发送的图像自动以更高保真度处理。
- 更高分辨率意味着更多 token 消耗，不需要高保真度的用户应提前下采样。
- XBOW 的视觉敏锐度基准测试从 54.5%（Opus 4.6）跃升至 **98.5%**（Opus 4.7）——这是该团队"最大的痛点实际上消失了"的步进式改进。

### 任务预算（Task Budgets，公开 Beta）

开发者可以引导 Claude 的 token 支出，使其在长运行中优先处理关键工作。这与 xhigh effort 配合使用，形成更精细化的计算资源管理。

### /ultrareview 命令（Claude Code）

新的斜杠命令启动专用的审查会话，读取变更内容并标记一个仔细审查者会发现的错误和设计问题。Pro 和 Max 用户享有 3 次免费 ultrareview。

## 范式对比

### Anthropic Opus 4.7 vs OpenAI GPT-5.6 安全方法论

| 维度 | Anthropic Opus 4.7 | OpenAI GPT-5.6 Sol |
|------|--------------------|--------------------|
| 核心策略 | **差分能力压制** | **多层安全堆栈** |
| 训练阶段介入 | 是——训练中主动降低网络战能力 | 否——安全主要在推理层和系统层 |
| 能力保留 | 刻意不完全释放 | 完整释放（Sol/Terra/Luna 均达到"High"生物和网络能力评级） |
| 高风险处理 | 训练内嵌阻断 + 受控豁免通道 | 多层过滤 + 压力测试 + 系统加固 |
| 研究访问 | Cyber Verification Program（受控认证） | 有限预览（trusted partners） |
| 自我推理控制 | 未公开披露 | 1.3%（5k-token CoT），较 5.5 的 0.4% 三倍——**主动标记为待调查** |
| 透明机制 | System Card | System Card |
| 能力-安全关系 | 安全约束定义能力边界 | 安全层约束已释放的能力 |

**关键差异总结：**

Anthropic 选择在**模型训练时**嵌入安全约束——通过训练让模型在某些领域"实际上不那么能干"。这是一种更深层的安全策略，代价是模型在这些领域无法达到完整前沿水平。

OpenAI 选择在**模型训练后**叠加安全层——释放全部能力，然后通过系统级 guardrail、内容过滤、行为监控来管控风险。GPT-5.6 的报告显示 Sol 的自我推理控制率（CoT controllability）在单一世代内从 0.4% 跃升至 1.3%（约 3 倍），这一趋势被明确标记为"正在积极调查中"——说明后置安全层面对快速演进的能力时可能存在压力。

两者的根本分歧在于：
- **Anthropic**：减少危险能力本身，从源头降低风险。
- **OpenAI**：保留全部能力，通过多层防御系统管理风险。

这两种范式的长期有效性将取决于：(1) 差分压制是否能持续有效（模型是否会通过微调或 prompt 工程恢复被压制的能力）；(2) 多层安全堆栈在面对持续改进的模型能力时的可扩展性。

## 可复用的工程经验

1. **将安全约束嵌入训练过程**。在训练阶段减少特定危险能力比事后过滤更彻底、更难以绕过。这要求训练团队对模型能力谱系有精准的测量和控制。

2. **渐进式安全部署**。先在次前沿模型（Opus 4.7）上实验新安全机制，再推广到完整前沿模型（Mythos）。这降低了试验风险，同时允许在实际部署中收集数据。

3. **受控例外通道**。Cyber Verification Program 式的"压制 + 豁免"机制比完全封锁或完全开放都更有可操作性。关键在于建立可信的认证标准和审计追踪。

4. **Tokenizer 变更的影响评估**。任何 tokenizer 变更都不是免费的——1.0–1.35× 的 token 膨胀是架构 tradeoff 的直接体现。在提供更好质量的同时需要用户调整 token 预算。迁移指南和测量建议（"建议在实际流量上测量差异"）是降低迁移摩擦的关键文档实践。

5. **Effort 级别的细粒度化**。从 high/max 两档扩展到 high/xhigh/max 三档，反映了对推理深度-延迟曲线的更深入理解。为用户提供细粒度旋钮比单一大模型更实用。

6. **真实用户引言的工程价值**。Anthropic 的发布策略大量引用合作伙伴（Cursor/Notion/Devin/Replit/Harvey/XBOW 等）的定量评价。这些"第三方执行的真实工作负载评测"比纯粹的学术基准更有说服力，是 B2B AI 产品发布的标杆做法。

7. **回顾性指标修订**。Anthropic 在本次发布中修订了 Opus 4.6 的 CyberGym 分数（66.6 → 73.8，因优化了评测参数以更好地激发能力）。这展示了在快速演进领域保持基准可比性的挑战——在宣布新模型时，诚实修订旧基线比硬造提升数据更可信。

8. **指令跟随的回归风险**。Opus 4.7 的指令跟随显著提升，导致为旧模型编写的 prompt 可能产生意外结果——旧模型"松散或跳过"的指令现在会被字面执行。这提示重大能力更新需要伴随 prompt 和评估框架的重新校准。
