# Two-Version Output Workflow

Origin: 2026-06-09 session with user 杜昊天. After writing three comprehensive reviews, the user requested that every review be maintained in two versions:

## Version Definitions

| Aspect | Essay/Literary Version | Academic Version |
|--------|----------------------|-------------------|
| Filename suffix | `-v3.md` or none | `-v3-academic.md` |
| Tone | Flowing prose, narrative | Objective, measured |
| Opening | "钉子开门" - specific data point as hook | Direct factual statement |
| Voice | Can use "我们" for narrative flow | Third person, passive, or "本文" |
| Rhetorical questions | Allowed | Removed |
| Informality | "这是基础化学" style OK | "源于基础化学限制" style |
| Scene-setting | "一根鼻咽拭子从患者鼻腔取出后..." | "三种商业化POCT产品均宣称样本进-结果出..." |
| Structure & data | Identical to academic | Identical to essay |

## Conversion Procedure

1. Write the essay version first (it has more creative freedom)
2. Copy to academic version
3. Apply conversion rules:
   - Cinematic openings -> direct factual statements
   - Informal assertions -> measured academic phrasing
   - Remove rhetorical questions
   - Remove "我们" as narrative voice
   - Keep all citations, data, tables, and section structure identical
4. Verify both versions have the same reference count and DOI coverage
