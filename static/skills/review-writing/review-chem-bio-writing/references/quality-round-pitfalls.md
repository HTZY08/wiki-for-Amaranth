# 质量轮实战陷阱记录

本文件记录金纳米综述质量轮（Phase 10，2026-06-04）中解决的问题类型和修复方法。

## 陷阱1：注入段与正文重复

**识别：** 注入段标题与正文主题词完全一致；开头3句同一组事实+同一组作者+同一组DOI。
**合并：** 正文叙事流为骨架；注入段独特定量数据嵌入对应论点后；删除重复DOI。
**案例：** §3.1 46KB→23KB，引用数不变。
**检测方法：** 注入段小标题与正文主题词完全一致 → 读取开头3句 → 同组事实+同组DOI → 合并。

## 陷阱2：文献阅兵式段落

**裸DOI列表：** 无叙事连接词罗列论文 → 除非含独特信息，整段删除。
**「A等…B等…C等…」链条：** 5+连续引用，连接词仅「进一步/也/同时」 → 每3-4条插入一句评述。
**高发节：** §2.3、§4.1-4.2末尾、原§6（ML段）。特征：多轮subagent并行注入。

## 陷阱3：综述腔引用句式

`X等在其里程碑式综述中系统总结了` → 以现象为主语，不是课题组。
`X等致力于/深入研究了/系统考察了` → 换为「X等研究了/发现了/报告了」
`值得注意的是` → 删除。
**核心规则：** 综述不是关于综述的综述。首句是人名即重写。

## 陷阱4：年份被正则截断

`[Faraday 1857](doi)` → 脚本输出丢失1857。
**根因：** `re.sub(r'\s+\d+.*$', ...)` 误杀年份。
**修复：** 作者和年份独立处理。先提取年份，再移除，不混操作。验证：对每个测试字符串输出分隔后的 author/year/journal。

## 陷阱5：双括号累积

`([text](url))` → `((Author, DOI:...))` → `content.replace('((', '(').replace('))', ')')`

## 陷阱6：全角/半角括号混用

`（...）` 和 `(...)` 混用 → 先统一为英文半角。

## 陷阱7：DOI 从 URL 还原

`DOI:[text](url)` 格式 → 提取 URL 后构造 `DOI:10.xxx/xxxxx`。

## 陷阱8：批量脚本仅覆盖80-90%

逐节抽检3-5条引用。patch工具做定点修复，不迭代脚本。

## 陷阱9：从最烂的节开始

先扫再修。实战顺序：§3.1（冗余注入）→ §4.3-7（文风漂移）→ §2.3（文献阅兵）。

## 陷阱10：L3/L4/L5标签残留

`## L3 量化层` / `### L4 差距层` / `**L5：...**` 三种格式。用rm_labels.py处理。

## 陷阱11：用户授权文献增减

质量轮第二层授权「为逻辑顺畅可增减文献」。无需锁定引用数。
