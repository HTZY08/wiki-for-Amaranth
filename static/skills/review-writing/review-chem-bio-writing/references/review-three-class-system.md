# 三篇综述体系（2026-06-09项目）

从用户毕业论文第一章(巨型综述)拆分为三个独立方向的综述，每篇有自己的分析框架和目标期刊。

## 综述①：POCT核酸检测

**分析红线**：简化-代价交换——核酸检测POCT化的每一次简化(取消热循环、省去提取、放弃荧光读出)都在一个维度上获得了收益但在另一个维度上付出了可量化代价。

**章节结构**：
- §1 引言：开放式数据锚点(Cepheid vs ID NOW LOD差距)
- §2 样本前处理：被低估的第一道瓶颈(抑制剂+提取回收率+校正因子框架)
- §3 扩增技术：四项简化决策(PCR微型化/LAMP/RPA/RCA及其近期前沿)
- §4 CRISPR-Dx：一个独立的检测范式(非等温扩增延伸)
- §5 信号读出：光度链的层级简化(PMT→人眼)
- §6 三种集成逻辑(纸基/离心/数字微流控)
- §7 学术LOD与商业产品的断层(五因子乘积框架)
- §8 结论

## 综述②：微流控POCT

**分析红线**：三面墙——物理约束(好效应坏效应捆绑出现)、制造断层(PDMS vs 热塑性塑料)、集成化困境(步数乘积灾难)。

**章节结构**：
- §1 引言：2,500篇论文产生1个产品
- §2 微尺度物理的双刃剑
- §3 学术制造与商业制造的断层
- §4 系统集成与可靠性
- §5 四条技术路线的能力边界
- §6 商业化与产业转化(成功产品的设计规则)
- §7 结论与展望
