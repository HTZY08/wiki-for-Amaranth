世界模型工作法 Renhuai123/world-model-method
★ 19

让 AI「规划出」答案，而不是「顺嘴生成」。基于 Yann LeCun 的世界模型理论， 6 步工作法：定目标 → 建模 → 预测后果 → 搜索规划 → 渲染 → 自检。 原本是 Claude Skill，可无缝接入 Hermes。

LeCun 世界模型 6 步法 Claude Skill System-2
为什么装

默认的 Hermes 骨架模型也是 token-by-token 顺嘴生成的。 这个 skill 给它装了一个"思考引擎"——重要决策先规划再产出， 方案质量靠比选不是靠运气。

GitHub ⚡ 已集成 Skill
🌊
MiroFish 666ghj/MiroFish
★ 65.3k

群体智能预测引擎——输入种子信息（新闻/政策/故事），自动构建高保真平行数字世界。 数千个拥有独立人格、长期记忆和行為邏輯的智能体在其中自由交互、社会演化。 从上帝视角注入变量，推演未来轨迹。

群体智能 多 Agent 模拟 GraphRAG Docker
为什么装

Hermes 做信息收集和结构化，MiroFish 做深度推演。 两个配合：Hermes 搜热点 → 整理种子材料 → 送入 MiroFish 跑千 Agent 模拟 → 拿推演结果做决策。从"查资料"升级到"预演未来"。

GitHub 在线 Demo

ECC affaan-m/ECC
★ 209k

Everything Claude Code — 跨平台 Agent 性能调优系统。 64 个专业 Agent（planner、architect、code-reviewer、security-reviewer…）、 261 个 Skills、14+ MCP 服务、 12+ 语言生态。支持 Claude Code / Codex / Cursor / OpenCode 全平台。

64 Agents 261 Skills MCP 服务 跨平台
为什么装

ECC 的 64 个 Agent 定义可直接译为 Hermes 的 delegate_task 子任务 prompt。 261 个 Skills 是 workflow 模板的宝藏库——遇到"怎么写 PR 描述"、 "怎么做安全审计"这类重复需求，直接翻 ECC 的 skill 目录找现成的。

工作流示例：
你说"帮我分析一下最近 AI 融资趋势" → Hermes 搜全网整理成结构化数据 → 世界模型工作法 规划分析框架 → MiroFish 进行多 Agent 推演 → ECC 的 agent prompt 做交叉验证 → 输出完整分析报告，每一步都可追溯。
