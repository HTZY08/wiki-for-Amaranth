# Wiki 分类规则

> 适用于 Amaranth & Begonia Wiki。新内容按此规则归档，保持结构一致。

## 顶层分类

| 板块 | 路径 | 内容类型 |
|------|------|---------|
| **AI云组会** | `ai-daily/` | AI 领域每日动态、热点速递 |
| **Hermes Agent** | `hermes/` | 系统搭建、配置、集成、运维、参考 |
| **博客** | `blog/` | 长文、深度分析、横评 |
| **项目** | `projects/` | 做过的东西——每个项目一个文件夹 |
| **Skill 分享** | `skill-share/` | Kanban Worker Profile |
| **Begonia 协作** | `notes/begonia/` | 时效更新、运维快报、补充批注 |
| **白嫖指南** | `freebies/` | 免费 API、白嫖攻略 |
| **折腾记录** | `notes/tinkering-timeline.md` | 技术时间线（单页） |

## Hermes 子目录划分

按**实际使用场景**分，不是按功能模块分：

| 子目录 | 场景 | 举例 |
|--------|------|------|
| **部署** | 只做一次的事 | 环境准备、Docker、代理、GPU、兜底 |
| **配置** | 日常在调的事 | 模型路由、技能、记忆、定时任务 |
| **集成** | 对接外部系统 | 微信、Codex、BigSet、插件 |
| **运维** | 遇到才查的事 | 服务器配置、排障、架构、速查表 |

## 归属判断

- **这是系统的什么？** → 核心系统 → Hermes Agent
- **这是做了什么？** → 独立交付物 → 项目
- **这是信息搜集？** → 有深度 → 博客；短平快 → AI云组会
- **这是白嫖省钱？** → 白嫖指南
- **这是 Worker 配置？** → Skill 分享

## 禁止

- 不在顶层目录直接放文件（index.md 和 amaranth.md 例外）
- 不把不同主题塞进同一文件
- 不在 notes/ 下新建顶层子目录（notes/ 只保留 begonia/ + tinkering-timeline）
