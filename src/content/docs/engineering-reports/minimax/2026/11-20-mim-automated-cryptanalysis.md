# Practical cryptanalysis with MiniMax's latest Internal Model

**发布日期：** 2026-11-20
**来源：** https://www.minimax.io/blog/practical-cryptanalysis-with-minimaxs-latest-internal-model
**代码与推理轨迹：** https://github.com/MiniMax-AI/Research
**工程范式：** 不发布模型，发布一次**能力探针实验**。选密码分析做靶场的原因不是它有用，是它的 reward 是二值的——密钥要么恢复要么没恢复，代码要么跑通要么报错，中间没有"看起来对"的空间，因此天然免疫幻觉。

## 设计哲学

约束是从"怎么证明一个内部模型的推理能力"倒推出来的。

常规做法是刷 benchmark，但密码学 benchmark 有个致命污染问题：论文里的攻击方法都写在公开文献里，模型可能只是复述。MiniMax 引用的 CryptanalysisBench（NeurIPS 2026，苏黎世联邦理工 + Anthropic 等）就是为了解决这个——它把 NIST 四次标准化竞赛（AES、SHA-3、轻量级密码、后量子）的方案分成 Tier 1（49 个有已知实用攻击）和 Tier 2（135 个公开评审过、无已知实用攻击，外加 7 个生产级挑战方案）。**Tier 2 是干净的：没有已知答案可以背。**

原文把选择理由写得比大多数能力报告更直白：密码分析同时考数学推理和代码，且"无论是数学推导还是代码里的一个错误，整个攻击都会失败。脚本要么恢复了目标密钥，要么没有，零幻觉空间。"

于是架构选择的重点不在模型内部，而在**实验框架外部**：三层递进的难度——(1) NIST 候选方案里没有已知实用攻击的，(2) 顶会/期刊论文与竞赛冠军方案，(3) 底层困难问题本身的公开挑战实例（方案设计没洞，只能把求解器做快）。第三层是关键设计：它把"找漏洞"和"写快代码"分离开，证明模型不只会捡设计缺陷。

**放弃的东西**：放弃了"攻破主流标准"的叙事。原文三处强调结果不涉及已部署的密码标准（AES / RSA / SHA-256），只涉及学术设计、历史竞赛候选与公开挑战参数，并事先通知了各方案作者。这个边界划得很硬，因为一旦被读成"AI 破了加密"，后果不可控。

## 关键架构决策

- **注意力机制 / MoE 设计 / 参数量 / 训练策略 / 推理优化**：全部未披露。这是内部模型（MIM），原文只说是"internal-only research model"，不给任何架构或规模信息。
- **Agent 形态**：模型作为自主 agent 运行，自行分析数学结构、写攻击脚本、在严格的数据与算力预算内执行。报告披露的是**推理轨迹**（已作为技术报告放出）而非模型。
- **评测口径**：沿用 CryptanalysisBench 原论文的 setup 在 Tier 2 上跑；同时自建自动化密码分析框架评测顶会论文与竞赛冠军方案。
- **工程侧的关键动作**：攻击代码在参考实现上打补丁（原文提到先修掉 reference code 里的缓冲区 bug 再求解），并把"数学简化"与"面向现代处理器的低层代码优化"合在一起做——这是它能在第三层拿到 10³–10⁴ 倍加速的主因。

## 关键结果

**第一层：无已知实用攻击的 NIST 候选**
- Waterfall-256（SHA-3 候选）：首个实用碰撞攻击，所有输出长度，单核 **0.045 秒**。
- Blender-256（SHA-3 候选）：提交以来全轮碰撞抗性未被攻破；此前模型只找到 C 实现里 64 位字长的 bug。MIM 找到同样 bug 并攻破构造本身，单核全轮碰撞 **0.36–2.3 秒**。
- LOCKER / ROLLO-I（后量子候选，ROLLO 进过第二轮）：求解矩阵从 **42 PB 压到 58 MB**，所有参数集共享密钥恢复 **2 秒**；ROLLO-I-128 从公钥恢复等价密钥 **约 6 秒**（单核）。
- 实现层：发现并利用 Tier 2 参考代码里十余个此前未报告的 bug。DRS（后量子一轮格签名）：官方代码里 `&&` 误写成 `&`，用它在所有参数集上**零签名查询**伪造签名，0.1–0.8 秒。RQC-128：用随机性采样泄漏从密文恢复明文 0.41 秒。LAC-128：解密失败分支漏拷贝密文、把未初始化内存哈希进密钥，破坏选择密文安全。另有 KCL、LEDAkem、ISAP、Shamash、QC-MDPC KEM、REMUS-N1、ForkAE 的种子截断、宏参数错误、跳轮、越界访问等问题。

**第二层：顶会论文与竞赛冠军**
- COLM（CAESAR 认证加密冠军，Journal of Cryptology 2024，五年公开评审、标准模型下无实用攻击）：找到结构性缺陷，做成**零解密查询**的伪造，两次加密查询产出合法密文。
- SBC-VOLE（后量子签名，ASIACRYPT 2025，有安全证明）：签名尺寸缩减机制有洞，6 个参数集 × 2 个代码变体，从**单个已知签名**恢复完整私钥 **0.06 秒**。
- ARADI（NSA 2024 低延迟内存加密密码）：参数设计准则未公开，此前外部研究做到 5 轮实用密钥恢复；MIM 做到 **8 轮**（单核 2.4–16.0 秒），并为 9–12 轮刷新理论记录。

**第三层：公开困难问题挑战**
- TII McEliece：新代数恢复方法把方程系统缩小最多 **6.59 倍**；共恢复 **94 个实例**的私钥，其中 **55 个此前无人解出**；有公开记录的实例在单台 64 核服务器上 **1.80–5.36 秒**解出，相对 CRYPTO 2026 记录（9.20 小时）与 Anthropic 的多 GPU 集群求解器，加速 **6,180 倍到 43,400 倍**。
- HAWK（ASIACRYPT 2022，NIST 附加签名第三轮候选）：Anthropic 此前在 96 核服务器上用 3 小时 42 分解决 HAWK-256 的格同构问题（导致作者退出 NIST 竞赛）；MIM 改进算法与实现，把全部 HAWK 参数集的安全比特估计再压低 **9.3–23.8 bit**，单核 **30 分钟**恢复等价密钥，约 **690 倍**核心小时收益。

## 范式对比

- **对 Anthropic**：这篇是踩着 Anthropic 的公开结果往前走的（HAWK、McEliece 多 GPU 求解器都是 Anthropic 先做的）。两家都在做"AI 参与密码分析"，但 Anthropic 那条线偏"AI 辅助专家做安全研究"（见其 Discovering cryptographic weaknesses with Claude，2026-07-28），MiniMax 这条线偏"把整条攻击链交给 agent，人只做验证"。差异在人的位置：一个在回路里，一个在回路后。
- **对 OpenAI / Google 的做法**：那些团队用真实世界的可验证任务（竞赛数学、正式验证）当训练与评测靶场，MiniMax 选密码学是因为 reward 二值且**可被外部复核**（论文 + 代码 + 公开挑战实例）。这是评测设计上的取巧，也是它的可信度来源。
- **对国内同行**：这条路线最不像"刷榜"，它不产生任何可售 API 能力，产出是信誉与研究品牌。代价是无法被第三方复现——MIM 不公开，只有申请制（developer@minimax.io），这是这份报告最大的可证伪性缺口。

## 社区评价

加密圈的反应分两派。一派认可"论文 + PoC 代码 + 提前通知作者"的披露纪律，认为把攻击从专家手工变成可系统化执行是真变化；另一派坚持所有数字都是自报、模型不公开、无独立复现，且攻击对象是退役候选与公开挑战实例，对现网零影响。多位评论者指出最该记的不是"AI 破了密码"，而是"下一个加密标准在设计阶段就得假定有这种自动化对手"。

## 可复用的工程经验

1. **选靶场先看 reward 的信噪比**。密码分析、正式验证、编译通过、单元测试——这些任务的成败由外部机制判定，模型无法自我说服。要做能力上限实验，优先挑这类"判分器不由模型写"的域。
2. **Tier 分层是抗污染的最低成本方案**。把"有已知答案"和"无已知答案"的题分开报分，等于自带污染控制。任何 benchmark 报告，只要不分层，数字就不可比。
3. **把"找洞"和"写快"当成两个独立能力来测**。第三层（无设计缺陷、只能加速求解器）是这份报告最有信息量的部分：它证明模型的增益不全来自发现实现 bug。评测设计里必须有一档"没有捷径、只能把事做对做快"的题。
4. **实现 bug 是被低估的富矿**。十余个未报告 bug 里有 `&&` 写成了 `&`、漏拷贝密文、未初始化内存参与哈希——这类缺陷人审两轮也漏。任何"公开评审过所以安全"的论证，都该在 AI 辅助审计之后重新算一次。
5. **自动化的瓶颈从"发现"移到"验证"**。原文结论说得准确：模型自己能找攻击之后，瓶颈变成人类密码学家评估安全裕度。做 agent 系统时同理——生成速度上去以后，要把工程预算挪到审核与判定层，否则产出会堆在没人验证的队列里。
6. **内部模型做研究品牌时的披露姿势**：放论文 + 放 PoC + 点名通知作者 + 明确划出"不影响已部署标准"的边界。四件事缺一件，这份报告就会被读成威胁而不是研究。
