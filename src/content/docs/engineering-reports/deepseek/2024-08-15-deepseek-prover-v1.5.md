# DeepSeek-Prover-V1.5

**发布日期：** 2024-08-15
**来源：** arXiv 2408.08152
**工程范式：** 证明助理反馈强化学习（RLPAF）+ 好奇心驱动的 MCTS 搜索（RMaxTS）。

## 设计哲学

V1 的教训是：合成数据能带来大幅提升，但数据质量存在天花板。V1.5 从两个方向突破：一是引入 RL（GRPO），用 Lean 验证器的二进制反馈（0/1）作为奖励信号，让模型从自己的错误中学习；二是提出 RMaxTS——用内在奖励（intrinsic reward）驱动树搜索探索多样化证明路径，配合打折 UCB（DUCB）平衡探索-利用。同时，在 SFT 阶段为证明步骤插入自然语言 CoT 注释和 tactic state 中间状态，将"思考过程"显式引入训练数据。

## 关键架构决策

- **SFT 数据增强：** 用 DeepSeek-Coder V2 236B 为证明添加 NL 思维链注释，并插入 tactic state 注释，显式化中间推理过程
- **RLPAF：** 使用 GRPO（组大小 32），奖励来自 Lean 4 验证器，KL 惩罚 0.02。发现定理证明中 RL 能真正提升基础能力而非仅改善 TopK
- **RMaxTS：** tactic 级树搜索，用内在奖励实现好奇心驱动探索。虚拟节点技术统一模拟和扩展步骤。搜索后多次投票保留最优至少多样结果
- **截断恢复：** 提交完整证明到 Lean，在第一个错误处截断，将已证明部分转换为 tactic 树节点，然后从断点继续

## 关键结果

miniF2F test 上 Pass@128 达 63.5%，ProofNet 测试 25.3%，均刷新 SOTA。RMaxTS 搜索比贪婪解码提升 10+ 百分点。CoT 注释和 tactic state 增强对 SFT 效果提升约 5pp。RL 在基础模型上进一步贡献 2-3pp 提升。

## 范式对比

与 V1（纯数据驱动）相比，V1.5 证明了 RL + 搜索的结合是定理证明能力跃升的关键——两者叠加而非互相替代。与 AlphaProof 相比，RMaxTS 的内在奖励机制降低了搜索的 sample 成本。

## 可复用工程经验

1. 在形式化领域，RL 同样有效但效果不如 NL 领域显著——更适合作为 SFT 的补充
2. 搜索策略应和模型训练协同设计，RMaxTS 的截断恢复机制高效实用
3. 将中间推理状态（tactic state）显式加入训练数据是低投入高回报的优化
4. 验证器反馈是天然的高质量奖励信号
