# Kimi K3.1 Pro：不加参数，只加后训练

**发布日期：** 2026-10-24（官方研究页标注；API 于 2026-10-23 上线）
**来源：** https://www.kimi.ai/blog/kimi-k3-1-pro
**工程范式：** 底座冻结，把 RL 算力与工程栈做深——训练框架、长上下文推理、沙箱、rollout 调度一起优化，换取"每一份 RL 算力都稳定兑现"。

## 设计哲学

官方一句话定性：K3.1 Pro 是 **Kimi K3 的后训练版本**，"substantially larger post-training compute"。没有重新预训练、没有换架构，重点在于让大规模跨域联合 RL 可预测：官方说他们为了"联合 RL 跑几百个下游域"，逐层优化了 RL 框架、长上下文推理、训练效率、沙箱基础设施、rollout 调度，以及环境质量检查的共享平台。

这个思路和 z.ai 的 GLM-5.3 是同一流派（同一底座、只做 post-training），但 Kimi 的着重点是**RL 的工程吞吐**，而不是环境合成管线。代价是能力提升上限受底座限制；收益是迭代速度与成本。

## 关键架构决策

- 规模：官方称"3T-class open-weight"（3 万亿参数级），256K→**1M token 上下文**；具体总参/激活参数官方文中未给精确数（第三方转述为 2.8T 总参 / 104B 激活，属二手，未在官方页核实）。
- 底座继承 Kimi K3 架构（K3 报告曾披露 Kimi Delta Attention + attention residuals + 16/896 稀疏专家路由等设计，见 wiki 的 K3 分析），本文不重复。
- **RL 栈工程**：joint RL 跨数百域，重点是 rollout 调度与环境质量校验的共享平台。
- **两个交付形态**：K3.1 Pro 与 K3.1 Pro Highspeed（2–3× 速度）。
- 开源：完整权重承诺 11 月 4 日前发布（官方页面口径）。

## 关键结果

- Terminal-Bench 4.0：**65.7%**，高于 GPT-6 Astra（58.2%），略低于 Claude Opus 5.5（66.4%）。
- Kimi Code Bench 3.0 Long-horizon（内部）：**61.2%**，K3 为 55.95%。
- BenchCAD（多视图→CAD 代码，带工具）：**92.7%**，接近 Opus 5.5（96.2%）与 GPT-6 Astra（95.9%）。
- OfficeQA Pro v2（真实财报跨文档检索与多步数值推理）：**64.4**，官方称 SOTA。
- 一个有意思的长程案例：在 human-atlas 解剖模型（296 个骨骼组件、402 个肌肉组件）上搭人体步态模拟器，167 个任务、420 次独立评审；当奖励塑形无法改善手臂运动时，模型没有继续调奖励，而是跑了模拟器动力学的开环探针，定位并修正了 36 处肩部肌肉力臂计算错误，再重训控制器——最终模拟人在 11.2 秒内连续交替步态行走。这是"模型自己发现评测/环境本身有 bug"的少见公开案例。

## 范式对比

同为"底座不动只做后训练"，GLM-5.3 靠环境合成 + 验证器自造，把 Terminal-Bench 3.0 从 4.6 拉到 28.3；Kimi 靠 RL 吞吐与跨域联合训练，把 Terminal-Bench 4.0（更难的版本）做到 65.7%。两家都在证明：**后训练环境与算力调度，已经比预训练规模更能决定 agent 能力**。区别在透明度——Kimi 报了模型自我纠错的轨迹，z.ai 报了环境合成的流水线与 2,436 个真实漏洞。

## 社区评价

第三方评测（如 LiveBench 2.0 的 11 月表）显示其编码分 67.8（K3 为 53.1），长程 agent 36.0→38.7，属于"真实提升但在开源模型里仍居中游"。这一结论来自二手汇总，引用时需回查榜单原始数据。

## 可复用的工程经验

1. **先修 RL 基础设施再谈算法**。rollout 调度、沙箱、环境质检平台是吞吐上限，不修这些，加多少卡都换不来线性收益。
2. **跨域联合 RL 能带来"每域都涨"的效果**，前提是各域的环境质量可被统一校验。
3. **让模型有能力质疑环境**。步态案例里最有价值的动作不是调参而是查 bug——训练环境里埋着系统性错误时，允许模型做开环探针会救回整条曲线。
4. **同权重出高速版**是低成本的交互体验优化，不用重新训练。
5. **权重发布承诺要留缓冲**。官方说 11 月 4 日前，实际到点发布才算闭环；对外承诺与合规审查要并行排期。
