# AlphaFold 3

**发布日期：** 2024-05-08  
**来源：** Nature 2024  
**工程范式：** Agentic 能力密度路线——用扩散模型预测所有生命分子的联合结构。

## 设计哲学

AlphaFold 3 超出了蛋白质结构预测的范畴，进入 **生物分子相互作用的全方位预测**。与 AlphaFold 2（仅预测蛋白质结构）的根本不同在于，AF3 可以预测 **蛋白质、DNA、RNA、小分子配体、离子和修饰残基的联合三维结构**。

核心方法转变：从 AlphaFold 2 的结构模块架构 **切换到扩散模型（diffusion-based architecture）**。这使其能够处理任意分子组合，而不需要为每种分子类型设计专门的子模块。

## 关键架构决策

- **扩散架构：** 基于扩散的生成模型，替代 AF2 的 Evoformer + Structure Module 架构
- **联合结构预测：** 单一模型同时预测蛋白质-蛋白质、蛋白质-核酸、蛋白质-小分子、蛋白质-配体的相互作用
- **输入：** 蛋白质序列 + 可能的分子组合
- **输出：** 所有原子的 3D 坐标
- **发布：** 开源代码 + 免费的 AlphaFold Server 平台

### 关键结果

#### 各分子类别精度对比

| 分子类别 | AlphaFold 3 | 专业化工具 | 提升幅度 |
|---------|------------|-----------|---------|
| 蛋白质-配体相互作用 | **显著更高** | SOTA 对接工具 | 大幅提升 |
| 蛋白质-核酸相互作用 | **显著更高** | 核酸特异性预测器 | 大幅提升 |
| 抗体-抗原预测 | **显著更高** | AF-Multimer v2.37 | 大幅提升 |
| 蛋白质结构预测 | **匹配或更好** | AlphaFold 2 | ≈ 或 ↑ |

#### 与专业工具对比

> "In all but one category, it achieves a substantially higher performance than strong methods that specialize in just the given task."

关键发现：**AlphaFold 3 的通用模型在每个类别上都匹配或超越了专门为该任务设计的工具**——这是通用模型 vs 专业化工具的又一次胜利。

### AlphaFold 数据库

- 通过 EMBL-EBI 发布了 **超过 2 亿个蛋白质结构的预测结果**
- 覆盖近乎所有已知目录中的蛋白质
- AlphaFold Server 向科学界免费开放非商业研究使用

## 范式对比

| 维度 | AlphaFold 2 | AlphaFold 3 | 传统对接工具 |
|------|------------|------------|------------|
| 核心架构 | Evoformer + Structure Module | **扩散模型** | 物理模拟 |
| 覆盖分子 | 蛋白质 | 蛋白质+DNA+RNA+配体+离子+修饰 | 特定类型 |
| 预测类型 | 蛋白质结构 | 分子联合结构 | 分子对接 |
| 通用 vs 专用 | 蛋白质专用 | **通用** | 专用 |
| 开源 | ✅ | ✅ | 部分 |

## 可复用的工程经验

1. **扩散模型是比专门结构模块更好的生物分子结构预测架构** —— 灵活处理任意分子组合
2. **通用模型可以匹敌甚至超越专业化工具** —— 这在生物学领域是一个颠覆性的结论
3. **联合结构预测（而非单分子预测）解锁了药物发现的新范式** —— 蛋白质-配体相互作用的精确预测是 AI 药物研发的圣杯
4. **2亿+ 结构数据库是无可替代的数据飞轮** —— 每次预测都在丰富结构空间
5. **开源 + 免费平台的双重发布策略最大化科学影响力**
