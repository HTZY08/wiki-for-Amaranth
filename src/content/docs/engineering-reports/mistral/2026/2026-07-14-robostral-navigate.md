# Robostral Navigate：单摄像头 RGB 导航的规模化训练范式

**发布日期：** 2026-07-14（arXiv 提交）
**来源：** https://arxiv.org/abs/2607.20785
**工程范式：** 最小传感器假设 + 纯仿真训练 + 前缀缓存（prefix-caching）高效训练 + 在线 RL（CISPO）精调——以单 RGB 摄像头超越深度/多摄像头方法

## 设计哲学

**核心约束：** 机器人导航的规模化部署受制于传感器依赖——深度传感器、LiDAR、多摄像头模组增加了部署成本和硬件兼容性。每个额外传感器缩小了兼容机器人平台的范围，增加了环境标定需求。

**架构选择：** Robostral Navigate 围绕"可规模化食谱"组织设计：
- **只需要单目 RGB 摄像头**——最广泛可用的传感器（从仓储车轮到配送无人机）
- **指向式导航（pointing）**——在图像空间（像素坐标）中预测路径点，而非机器人专属的度量坐标，使策略对摄像头内参和场景尺度变化天然鲁棒
- **纯仿真训练**——350k 场景 × 240 万轨迹，消除对昂贵真实数据采集的依赖
- **前缀缓存训练**——将完整 episode 打包为单条训练序列，token 量减少 22×

**放弃了什么：**
- 放弃了对深度/LiDAR 的依赖（没有使用任何 3D 感知），这在灾难场景或烟雾环境中可能是限制
- 放弃了离线真实数据采集（依赖 Habitat 仿真器的保真度）
- 将粗粒度路径规划（VLM）与细粒度运动控制（轻量扩散策略）分离——VLM 以 0.5Hz 推理，扩散策略以 10Hz 运行，控制器以 100Hz 执行

## 关键架构决策

### 1. 视觉语言模型（VLM）

- **参数规模：** 8B（密集，非 MoE）
- **初始化：** 从面向空间定位任务的 8B 密集 VLM 初始化（定位、计数、目标定位——这些能力自然泛化到导航）
- **视觉编码器：** 将 RGB 帧编码为视觉 token 序列，与 tokenized 指令拼接
- **输入历史：** 多帧 RGB 历史使模型能推理已访问位置和追踪进度

### 2. 指向式导航 + 度量位移回退

| 模式 | 触发条件 | 输出 | 优势 |
|------|---------|------|------|
| Visual Pointing | 目标在视野内 | 像素坐标 (u,v) + 航向角 Δθ | 不依赖摄像头内参，跨平台无需重标定 |
| Metric Displacement | 目标在视野外 | 位移 (Δx,Δy,Δθ) | 保证始终可推进 |

指向模式是首选——输出在图像空间而非机器人坐标空间，自然解耦于具体机器人形态。

### 3. 扩散策略桥接层

- **参数：** ~121M DiT（Diffusion Transformer）
- **输入：** VLM 预测路径点 + 机器人高度/半径 + 最新 RGB 帧 + 当前 RGB 帧
- **输出：** 30 步 action chunk（10Hz 轨迹，对应下一秒）
- **作用：** 将粗粒度 VLM 路径点转换为细粒度运动轨迹

### 4. 前缀缓存训练（Prefix-Caching）

**核心创新：** 受 Molmo2 注意力掩码的启发，将完整 episode 编码为单条训练序列：

- **传统做法：** 每个时间步独立处理 → 总计算量 O(T²)
- **Robostral 做法：** 将所有时间步打包为 `I|O₀|a₀|O₁|a₁|...|Oₙ|aₙ` → 总计算量 O(T)
- **树状注意力掩码：** 防止模型在前向传播中看到历史上 groundtruth action（否则模型会依赖 future info，导致训练-推理 mismatch）
- **效果：** 训练 token 减少 22×，训练时间从数月缩短为天数

### 5. 在线强化学习（CISPO）

- **算法：** CISPO（group-relative advantage estimation，自校准学习信号）
- **奖励设计：** -max(2, dist_to_goal)——距离目标 2m 内 reward flatline，激励 agent 发出 STOP
- **环境：** 协调 vLLM 推理 + 物理仿真渲染 + 分布式训练三路 GPU 负载
- **隐式视觉课程学习：** 按场景打包任务（同一场景的连续 rollout），每个 batch 包含共享视觉上下文的多条 episode → 比随机打乱效果好 4%
- **效果：** SFT baseline 73.40% SR → RL 后 77.43% SR（+4.03%）
- **失败筛选：** 仅保留 SFT 策略失败的那 35k 任务子集进行 RL（聚焦计算在薄弱环节）

| 传感器 | 单 RGB | RGB / RGB-D | RGB-D | RGB-D |
| 输出空间 | 图像坐标 → pointing | 度量坐标 | 度量坐标 | 度量坐标 |
| 参数量 | 8B VLM + 121M DiT | 4B / 8B VLM | 未公开 | 未公开 |
| 训练数据 | 350k 场景 × 240 万轨迹（纯仿真） | 仿真 + 真实 | 仿真 | 仿真 + 真实 |
| 训练效率 | 22× token 减少（前缀缓存） | 标准 | 标准 | 标准 |
| RL 精调 | CISPO（在线 RL） | 未公开 | 未公开 | 未公开 |
| 跨平台 | ✓（Galaxea R1 + Hiwonder JetAuto） | 未展示 | 单一平台 | 未展示 |

**关键差异：**

1. **输出空间转换（指向式 vs 度量式）：** Robostral Navigate 将导航问题重定义为图像空间中"下一个目标在哪"，而非"移动多少米"。这使得策略不依赖于机器人几何参数——同样的权重可部署在形态完全不同的平台上。

2. **训练效率：** 前缀缓存将训练 token 减少 22×，这是本文最具工程价值的贡献——不是通过压缩模型或降低质量，而是通过改变数据组织方式（O(T²) → O(T)）。任何顺序决策模型（机器人、自动驾驶、游戏 AI）都可受益。

3. **纯仿真训练 + RL 精调：** 240 万轨迹全部来自 Habitat 仿真器，无真实数据。然后通过在线 RL（与环境交互）补足 SFT 训练暴露偏差——RL 在模型真正会犯错的状态空间上学习恢复行为。

## 社区评价

Mistral AI 在 2026 年 7 月中旬发布了 Robostral Navigate 的新闻和博文。这是 Mistral AI 首次涉足具身 AI 导航领域（此前主力在 LLM 和代码模型）。技术社区的主要讨论点：
- **传感器最小化是正确方向：** 单 RGB 摄像头策略降低了硬件准入门槛
- **前缀缓存的工程价值：** 22× token 减少是一个在不同序列决策任务中可广泛复用的技巧
- **Mistral 的具身 AI 战略：** 从 Ministral 3（小模型）→ Leanstral 1.5（形式化证明）→ Robostral Navigate（机器人导航），Mistral 在 LLM 之外建立了多个特化模型产品线

## 可复用的工程经验

1. **前缀缓存（Prefix-Caching）适用于任何序列决策模型：** 核心思路是将完整 episode 打包为单条训练序列 + 树状注意力掩码，而非每个时间步独立处理。这对以下场景均有价值：
   - 机器人轨迹规划
   - 多轮对话中的上下文管理
   - 游戏 AI 的序列决策
   - 长视频理解

2. **隐式课程学习（按场景打包 Rollout）：** 同一场景的多条探索轨迹共享视觉上下文，使每个 batch 的信息密度更高、学习信号更强。这是"免费的课程学习"——不需要显式设计难度递增的数据调度器。

3. **RL 聚焦失败子集：** 不要在整个训练集上跑 RL——先评估 SFT 策略，仅保留失败轨迹子集（35k/240万≈1.5%）用于在线 RL。计算资源集中在提升薄弱环节而非冗余。

4. **指向式输出解耦机器人形态：** 在图像空间定义动作比在度量空间更通用。如果设计跨平台策略，优先考虑"指向"范式——不用为每个平台重新标定和训练。

5. **VLM + 轻量控制器分层架构：** 粗粒度 VLM（8B，0.5Hz） + 细粒度扩散策略（121M，10Hz） + 运动跟踪控制器（100Hz）——不同层次的时序粒度和计算复杂度匹配不同的硬件资源。推理时不需要将大模型跑高频。
