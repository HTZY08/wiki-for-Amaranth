# 工程汇报

本栏目对全球各大 AI 模型公司的技术报告进行深度工程范式分析。

每篇分析不是论文摘要复述，而是：

- 设计哲学：这家公司的核心约束是什么，面对约束做了什么架构选择、放弃了什么
- 关键架构决策：注意力/MoE/训练/推理/RL 的具体选型与原因
- 工程范式：这家公司代表哪种路线，和其他公司的差异在哪
- 可复用的工程经验
