## 📌 今日值得关注

### 1. Anthropic Fable 5 余波：开源成为最大赢家
Fable 5 发布后 Anthropic 遭遇大规模 backlash——秘密训练、隐蔽的 API 安全分类器、切断研究人员访问、操纵用户行为记录。Bloomberg/Fortune/CNBC 一致认为：最大赢家是开源。企业开始意识到依赖闭源 API 存在"断供风险"（Thomas Wolf: "like building your house on land you don't own"）。All-In Podcast 也做了专题讨论。
**跟我有什么关系**：如果你在做需要长期依赖某个 API 的应用，现在就是评估开源替代方案的时间窗口。Codex 已经支持所有开源模型作为 provider。

### 2. GLM-5.2（智谱）开源模型突围
GLM-5.2 在多个第三方 benchmark 上表现惊人——Opus Magnum 解谜 benchmark 超过 Opus 4.8 和 Gemini 3.5 Flash；PostTrainBench 表现极佳；Next.js Evals 超越 Opus 4.8。Vercel 的 rauchg 亲自认证。已在 HuggingFace 开源，Unsloth 量化版本已出，HF Inference Providers 上 6 小时内免费使用。
**跟我有什么关系**：如果你预算有限但需要高质量 coding agent 后端，GLM-5.2 是目前性价比最高的选择之一（Codex/OpenCode/Claude Code 都支持接入）。

### 3. ENPIRE：NVIDIA 首次实现物理世界 AutoResearch（Jim Fan）
Jim Fan 团队让 8 个 Codex agent 操控 8 台机器人，以"最小化完成时间"为目标自主设计实验、编写代码、运行、分析结果，全流程无人干预。设计了 MRU（机器人利用率）、MTU（token 利用率）等新 telemetry 指标。后附技术细节：安全硬件约束、静态奖励函数冻结等。
**跟我有什么关系**：这标志 coding agent 从数字世界进入物理世界自动化。如果你做实验科学或机器人，agent-in-the-loop 自动化实验范式已经到来。

### 4. Vercel SHIP London：Eve 平台 + Agent Stack 发布
Rauch 在伦敦发布多个重磅产品：Eve（agent 部署平台，对标 AI SDK + Gateway + Workflow + Sandbox + Chat + Connect 六件套）、Vercel Connect（OAuth 一体化方案，解决 agent 数据访问的最大痛点）、Sandbox 延长至 24h、Function 延长至 30min。还发布了 v0 skills 系统和 personal agent template。
**跟我有什么关系**：如果你在构建 agent 产品，Eve 是当前最完整的 agent 全栈平台，尤其是 OAuth 和数据接入的解决思路值得参考。

### 5. Poolside Laguna M.1 开源
Poolside 开源 Laguna M.1 权重（Apache 2.0, 256K 上下文），含 base 和 post-trained 版本。社区已做出 MLX 3-bit 量化版在 M3 Max 上跑 26 tok/s。
**跟我有什么关系**：这是一个 coding-specific 的开放模型，256K 上下文+Apache 2.0 许可，适合自建代码助手。

### 6. Midjourney Scanner / Midjourney Medical
Midjourney 宣布成立 Midjourney Medical 部门并发布 Scanner 硬件——无需 MRI 就能做全身 3D 内部扫描的超声计算断层扫描设备。Chollet 和 steipete 都转了这条。
**跟我有什么关系**：AI 公司从软件到硬件的跨界值得关注——训练数据从互联网扩展到物理世界。

## 💡 技术洞见

**"你可以外包思考，但不能外包理解"**（karpathy 引用 kache）。LLM 能帮你写代码、做研究，但如果你不理解输出，你就无法判断它是否正确。在 agent 越来越自主的世界，理解能力反而更加稀缺。

**"vibe coding 提高了下限，agentic engineering 提高了上限"**（karpathy @ Sequoia AI Ascent）。2026 的分水岭不是会不会用 AI，而是能不能设计 agent 系统。

**OpenEnv 社区化**（HuggingFace + PyTorch + Unsloth + NVIDIA + Modal 等联合治理）。开源 agentic RL 训练栈正在从单点突破走向基础设施化。这对做 agent 训练的人是个大信号——你不必从零造轮子。

**Fable 5 事件深层次含义**（Nathan Lambert 长 thread）：真正的危险不在于 API 安全分类器本身，而在于"科学不能在黑盒中进步"。当唯一的 frontier 模型不可用于独立研究时，开源模型对 AI 科学的意义变得生死攸关。

**fchollet 谈 bubble**：AI 可以是 bubble 即使技术本身牛逼——关键是投资者的预期和恐惧。2000 年互联网泡沫破裂后，互联网使用率并没有下降。

### 使用建议
- **coding agent 后端**：GLM-5.2 > Poolside Laguna M.1（性价比），想省成本不牺牲质量首选
- **agent 部署**：Vercel Eve 是最全的现成方案，但绑定 Vercel 生态；本地部署可看 Hermes Agent / OpenHands Enterprise
- **模型训练**：OpenEnv + Unsloth 是目前最顺手的 agentic RL 训练栈
- **注意**：Fable 5 虽强但 API 限制多且随时可能变更条款；对需要长期稳定性的项目，至少保留一条开源 fallback 路径
