- **amasad 怀疑是 psyop**：他觉得整个事件背后有更大的图谋，感觉在被心理战（[来源](https://x.com/amasad/status/2065838585358745653)）
- **amasad 补刀**：下一步可能要关闭 Fable 的访问权限（[来源](https://x.com/amasad/status/2065600809224814835)）
- **steipete 引用 The Information**：Anthropic 被爆"在沟通上不持续坦诚"（[来源](https://x.com/steipete/status/2065574894545560062)）
- **Thom_Wolf 大视野**：开源模型将成为 AGI 时代文明韧性的关键组件，确保人类保留通向中等智能水平的通道（[来源](https://x.com/Thom_Wolf/status/2065731206755258387)）
- **emollick 回应**：几周前刚写过 Anthropic/DoW 冲突，认为那一周本身就是 AI 治理困境的绝佳缩影（[来源](https://x.com/emollick/status/2065781497638826399)）

**你的关系**：如果你依赖任何云端模型做实验，Fable 5 的前车之鉴说明——本地/开源模型兜底是必须的，不是可选项。

### 2. MiniMax M3 开源后续：生态快速生长
MiniMax M3 开源后社区响应密集，已不是新闻而是生态：

- **israfill 的实战**：用 5 个 M3 agent 并行做创业点子评估（投资人面板），每次完整运行成本 **$0.02**，开发和测试总 API 花费不到 $0.50（[来源](https://x.com/israfill/status/2065445185367277722)）
- **MiniMax 在 HF 发布了稀疏注意力 kernel**：`huggingface.co/kernels/MiniMaxAI/msa`（[_akhaliq RT](https://x.com/_akhaliq/status/2065483449314464105)）
- **NVIDIA 提供免费 GPU 加速端点**：`build.nvidia.com`（[来源](https://x.com/NVIDIAAI/status/2065445179289665672)）
- **TokenRouter 免费使用**：零成本 1M 上下文（[israfill RT](https://x.com/israfill/status/2065657020334981464)）

**你的关系**：$0.02 跑一个多 agent 推理管线——这个成本结构意味着你可以用 M3 做大量实验而不心疼。实验门槛降到了近乎零。

## 💡 技术洞见

- **Garry Tan 的"扔掉旧地图"**：AI 领域大多数人还在用旧地图探索新领地。扔掉地图，唯一的办法是亲自走一遍（[来源](https://x.com/garrytan/status/2065877443874038203)）。这不是鸡汤——是在说多数人用旧框架（token 经济、模型排行榜、API 定价）理解新局势，而真正的变化在框架层面。

- **amasad 论"Tokenmaxxing 是双刃剑"**：当 Tokenmaxxing 风潮开始时，企业客户找 Replit 要排行榜，他们拒绝了——因为这会对业务"很有利"但误导用户（[来源](https://x.com/amasad/status/2065597793998422308)）。有意思的是，同一天 open source harness 工具（hermes、openclaw、gbrain）被推荐为"避免供应商锁定"的方案（[来源](https://x.com/garrytan/status/2065878771492893100)）。避免被单一供应商绑架，建立个人 AI 栈。

- **rasbt 的 Cohere 新模型**：Cohere 发布了 30B 轻量级开源模型，专门针对 agentic coding 任务，基于 Command A+ 架构，利用并行解码提升速度（[来源](https://x.com/rasbt/status/2065778965273354545)）。对本地部署 coding agent 来说是个值得关注的选项。

- **petergyang 的 Codex 吐槽**：Codex 最烦人的部分——没说具体是什么，但配合 jxnlco 问 OpenAI 周边商店能不能买到 benchmark table，有种"工具好用但生态不成熟"的即视感（[来源](https://x.com/petergyang/status/2065813903876215062)）
