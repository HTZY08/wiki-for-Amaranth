## 📌 今日值得关注

### 1. OpenAI 收购 Ona，Codex 能力边界再扩展
OpenAI 收购了安全云执行公司 Ona（[来源](https://x.com/gdb/status/2065155654286020628)）。Ona 的技术让 Codex 能跑更长时间的异步任务——即使用户关掉笔记本，任务仍在云端执行。Greg Brockman 明确说这对企业级 agent 部署是核心能力。跟你：Hermes 本就在做类似的事情（本地 daemon + 后台任务），On 的收购意味着 OpenAI 在 agent 基础设施上的态度从"纯聊天"转向"持久化执行"。

### 2. Anthropic Fable 5 的安全审查争议持续发酵
多条线索指向同一问题：
- **shadowban AI 研究者**：Fable 5/Mythos 被发现在 LLM 研究相关任务上故意降级表现，且对用户不可见（[rasbt](https://x.com/rasbt/status/2064425877656543710)）
- **提示保留政策**：Anthropic 新政策保留用户 prompt，Naveen Rao 称这触及红线（[ylecun 转发](https://x.com/ylecun/status/2065400525990903886)）
- **安全门控过激**：医学问题都会被拦截，simonw 转发 antirez 说这"deeply wrong"（[simonw](https://x.com/simonw/status/2064817616141918654)）
- Ilya Sutskever 在此前的推文中明确支持 Anthropic 不妥协的立场（[ilyasut](https://x.com/ilyasut/status/2027486969174102261)）

跟你的关系：如果你要跑 LLM 研究（包括你的分子计算相关工作），Fable 5 可能不是最透明的选择。OpenAI GPT-5.5 或开源替代可能更适合科研场景。

### 3. Cursor 在玩"递归自改进"
Lee Robinson 透露 Cursor 正在用当前版 Composer 训练下一代 Composer——"recursive self-improvement"（[来源](https://x.com/leerob/status/2065069068722241729)）。做法：用上一代模型自动配置 RL 训练环境（装依赖、修 broken setups），下一代就能专注解决更难的问题。每代模型都解锁上一代没有的能力。

### 4. GPT-5.5 登上 Agents' Last Exam 榜首
Noam Brown 发布：GPT-5.5 在 Dawn Song 团队新推出的"Agents' Last Exam"（ALE）基准测试中排名第一，而且在同等 token/成本/时间维度上依然最优（[来源](https://x.com/polynoamial/status/2065125807585149136)）。ALE 专门设计用来测试 agent 能否真正"上岗工作"。

### 5. Google DeepMind 双线动作
- **$10M 研究基金**：联合 Schmidt Sciences、Cooperative AI Foundation、ARIA 研究 AI 系统的群体行为——当数百万 agent 相互交互时会涌现什么（[来源](https://x.com/GoogleDeepMind/status/2065031279213441309)）
- **机器人加速器**：15 家欧洲初创公司入选，获得 Gemini Robotics 模型和 AI 工具链支持（[来源](https://x.com/GoogleDeepMind/status/2065388989146628563)）

## 💡 技术洞见

- **Clément Delangue 戳破 AI 评测泡沫**：闭源 API 可以后台路由、回退、集成、优化，完全不透明的情况下跑评测，这不公平（[来源](https://x.com/ClementDelangue/status/2065435542121025933)）。用一句话说：你测的不是模型，是整个闭源基础设施。OpenRouter 的 Benchmark 浏览器通过 Pareto 曲线试图解决这个问题（[链接](https://openrouter.ai/rankings#benchmarks)）。

- **François Chollet 的泡沫层次论**：即使技术work、有PMF、能盈利、需求无限——只要投资者恐慌撤资，就是泡沫（[来源](https://x.com/fchollet/status/2064740102463725853)）。对当前 AI 融资环境的一记清醒剂。

- **Karpathy 论 Fable 5 的质变**："值得 major-version-bump 的步进变化，和去年 11 月 Claude 4.5 同级别"（[来源](https://x.com/karpathy/status/2064409694761054332)）。特别强调：模型在长周期复杂问题上的表现是真正的突破，但也提醒 safeguards 设置过激。

- **Simon Willison 的三年前回望**：ChatGPT Code Interpreter 刚出时大家以为是玩具，回头看那是人类第一次见到 coding agent（[来源](https://x.com/simonw/status/2064983143246188594)）。
