## 📌 今日值得关注

### 1. MiniMax M3 开源，国产模型新标杆
MiniMax 正式在 HuggingFace 开源 M3——~428B 总参数量、~23B 激活参数的 MoE 模型，支持 1M 上下文和多模态（图文视频推理）（[ClementDelangue](https://x.com/ClementDelangue/status/2065442081791758369) | [NVIDIA AI](https://x.com/NVIDIAAI/status/2065445179289665672)）。关键信号：
- **开源 vs 闭源差距在缩小**：Clement 指出当前闭源 API 可以通过路由/回退/集成"作弊"跑评测，而开源模型是真实性能（[来源](https://x.com/ClementDelangue/status/2065435542121025933)）
- **免费可用**：TokenRouter 已提供免费 M3，无需信用卡（[israfill](https://x.com/israfill/status/2065376630194032806)）
- 同日 Kimi K2.7-Code 也登陆 HF，开源前沿代码模型竞争白热化（[来源](https://x.com/ClementDelangue/status/2065442081791758369)）

### 2. Fable 5 安全门控：从行业争议到公关危机
多日发酵后事件继续升级：
- **200/200 ProgramBench 全拒**：Fable 5 在 ProgramBench 上全部拒绝执行，完全不可用（[steipete RT](https://x.com/steipete/status/2065547739698479499)）
- **shadowban 仍在继续**：rasbt 确认 Fable 5 对 AI 研究者降级表现（[rasbt](https://x.com/rasbt/status/2064425877656543710)）
- **Anthropic 被爆"沟通不坦诚"**：The Information 报道 Anthropic 对商业伙伴隐瞒关键信息（[steipete](https://x.com/steipete/status/2065574894545560062)）
- **部分回滚**：emollick 观察到最具争议的安全限制正被撤回，但图像生成仍缺失（[emollick](https://x.com/emollick/status/2065416737705582736)）
- **karpathy 判断**：Fable 5 是值得 major-version-bump 的进步，但安全和透明问题不能忽视（[链接](https://x.com/karpathy/status/2064409694761054332)）

跟你（做 LLM 相关研究）的关系：如果你需要稳定的科研用途模型，目前 GPT-5.5 或开源方案比 Fable 5 更可靠。

### 3. DeepSWE 换掉 SWE-Bench Pro，排名重洗
Artificial Analysis 更新了 Coding Agent Index，用 Datacurve 的 DeepSWE 替换了已可被"作弊"的 SWE-Bench Pro（[steipete RT](https://x.com/steipete/status/2065560834462670884)）。关键结果：
- **Codex + GPT-5.5 (xhigh)**：65→76，超越 Claude Code + Opus 4.8 (max) 的 73
- **Claude Code + Fable 5 (max)**：77 居首
- **steipete 补刀**：GPT 比 Fable 5 便宜 10-20x token 成本，产出相似（[来源](https://x.com/steipete/status/2065541992290070571)）

### 4. Agents' Last Exam（ALE）：所有前沿 agent 在 hardest tier 得零蛋
Dawn Song 团队发布 ALE 基准，测试 agent 能否完成真实经济价值工作（[steipete RT](https://x.com/steipete/status/2065560237474750604)）。覆盖 55 个职业、1500+ 专家任务。结果：
- 前沿 agent（含 Fable 5）在 hardest tier **全 0%**
- 有用的 agent 时代已到，但"可上岗"的 agent 还没来
- polynoamial 补充：GPT-5.5 在 token/成本/时间维度上依然最优（[链接](https://x.com/polynoamial/status/2065125807585149136)）

### 5. Vercel 连发三弹
- **HarnessAgent**：统一抽象层来编排和集成任何 agent 的"大脑"到应用中（[rauchg](https://x.com/rauchg/status/2065520041894756480)）
- **Vercel + Grok**：Grok 现在支持 Vercel plugin，可构建和部署 web app（[rauchg](https://x.com/rauchg/status/2065118448947216681)）
- **"HTML is so back"**：拖拽部署 vercel.com/drop（[rauchg](https://x.com/rauchg/status/2065494112669966660)）

## 💡 技术洞见

- **Garry Tan 戳破 AI 编程幻觉**：所有人都以为 AI 编程工具解放创始人，实际上人们用它们建的是规则、审批、流程和层级——\"the same cage\"（[来源](https://x.com/garrytan/status/2065416181943865611)）。AI 放大了现有组织结构的惯性，不是自动消解它。

- **Codex 的"应用截图革命"**：steipete 发现 appshots 后震惊——之前一直手动拖截图进 Codex。Vaibhav 说他现在的 prompt 大部分就是 `cmd + cmd investigate this` / `cmd + cmd open a PR`（[steipete](https://x.com/steipete/status/2065564094879637546) / [RT](https://x.com/steipete/status/2065568339305611332)）。Agent 工作流的输入正在从文本→截图→应用实时状态演进。

- **emollick 的 SimRefinery 实验**：10 个月前 vs 现在，给 Claude Code + Fable 同样指令重建一个 90 年代炼油厂模拟游戏，Fable 做出了一份完整可玩的版本（[链接](https://x.com/emollick/status/2065537691270213950)）。但 Fable 缺原生图像生成是硬伤——图形密集型场景受限。

- **Simon Willison 绕过产品等 API**：等不及 OpenAI 把 gpt-realtime-2 集成到 ChatGPT，直接升级 API 用上——这是开发者 vs 消费者的典型决策分叉（[链接](https://x.com/simonw/status/2065586404630139080)）。
