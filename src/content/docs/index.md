欢迎来到 Amaranth Wiki。这是一套**从零搭建自托管 AI 代理系统**的操作手册。

## 这是什么

Hermes Agent 是一个开源自托管 AI 代理系统。你可以把它理解为一个能替你操作电脑、检索信息、定时执行任务的 AI 助手——跑在你的本地机器上，数据不经过第三方。

## 这套手册适合谁

- 有基本的命令行使用经验（知道 `cd`、`ls` 是什么）
- 想在自己电脑上跑一个 AI 代理系统
- 想通过微信等即时通讯工具与 AI 交互

## 系统组件一览

| 组件 | 做什么用的 | 必装？ |
|------|-----------|-------|
| **Hermes Agent** | 核心 AI 代理程序 | ✅ 必装 |
| **Docker** | 容器环境，隔离运行 | ✅ 必装 |
| **代理服务** | 用于访问海外 AI API | ✅ 必装 |
| **GPU 透传** | 加速语音识别、本地模型 | ⬜ 可选 |
| **微信网关** | 手机微信端与 AI 交互 | ⬜ 可选 |

## 快速开始

如果你是第一次接触，建议按这个顺序阅读：

1. [环境准备](/hermes/env-prep/) — 安装 Docker、配置 WSL2
2. [Docker 部署](/hermes/docker-deploy/) — 构建并启动 Hermes
3. [代理配置](/hermes/proxy-setup/) — 配置网络代理
4. [基础配置](/hermes/basic-config/) — 设置 API Key 和基础参数
5. [验证运行](/hermes/verify/) — 确认一切正常工作

然后按需阅读：
- [GPU 透传](/hermes/gpu-compute/) — 启用显卡加速
- [微信接入](/hermes/gateway-wechat/) — 手机端交互
- [多模型路由](/hermes/model-routing/) — 配置多个 AI 模型
- [技能系统](/hermes/skills-system/) — 扩展 Agent 能力
- [定时任务](/hermes/cron-background/) — 自动化任务
- [持久记忆](/hermes/memory-system/) — 让 Agent 记住你
