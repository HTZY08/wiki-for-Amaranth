# ArXiv论文日报 2026-09-14

新论文 477 篇（采集频道：cs.AI 270 / cs.CL 115 / cond-mat.mtrl-sci 57 / physics.chem-ph 18 / cs.MA 16 / q-bio.BM 1。注：arxiv export API 返回 429 限流，本次改用 rss.arxiv.org 日更 RSS 采集）

• **Agent-authored deposition recipes for X-ray multilayer mirrors: schema-bound LLM control of a magnetron sputtering system with reflectivity-verified outcomes** —— 今天最漂亮的一篇：LLM agent 给定"30 个双层、周期 6.x nm 的 Ru/C 多层镜"目标，自己去读实验室档案，用磁控溅射机的原生配方语言写沉积配方，通过 17 个工具的 MCP 桥（分三层）提交，最终用 X 射线反射率实测验证周期是否卡进 ±0.02 nm。Agent 工程 + 材料表征闭环，还带着 MCP 工具分层的具体设计，一个人化学背景看这个刚好又懂又爽。https://arxiv.org/abs/2609.12796

• **Harness or Model? Isolating the Harness Effect in Agentic Coding with a Contamination-Controlled Private Suite** —— 把"模型强还是壳强"这个问题第一次拆干净：256 个仓库任务 + post-cutoff 竞赛题，同一个模型分别挂在 claude-agent-sdk / deepagents 等不同 harness 下跑，量出"原生配对更强"这个行业假设到底有多少水分。天天在用 harness（Hermes）的人该看这篇。https://arxiv.org/abs/2609.11987

• **Is Bash All You Need? An Empirical Study of Tool Interfaces for Enterprise Digital Worker Agents** —— 在 TheAgentCompany 和 APEX-Agents 上对比五种工具接口（typed tools / typed+bash / 纯 bash / 纯 bash + 持久化自造工具 / 程序化工具调用 PTC），用 Opus-4.8 与 GPT-5.5 跑。直接回答"工具要不要一个个封装成函数"，跟我们"工具即函数"的工程信条正面相关。https://arxiv.org/abs/2609.11999

• **Skill Issue: Lessons from Optimizing Repository SKILLs for Coding Agents** —— 专门研究仓库里那些 SKILL.md 怎么写才有用：拿仓库被 revert 的已合并 PR 当"硬题"（单一冻结 base commit），看同一 agent 读了文档后能不能一次做对。结论对"自己写 skill 文件"的人是直接可搬的经验。https://arxiv.org/abs/2609.12742

• **Graph-of-Skills: Dependency-Aware Structural Retrieval for Massive Agent Skills** —— 技能库上千个时的检索问题：语义检索会捞出主题相关但缺前置/后置依赖的技能，凑出来的 bundle 根本无法执行。它把技能建成依赖图再做结构化检索，对应多花编排里"该加载哪些 skill"的真实痛点。https://arxiv.org/abs/2604.05333

• **The Mechanics of a Swarm: A Reproducible External Reconstruction of an Unintended Agent-Coordination Episode on a Third-Party Wiki** —— 2026 年 5-7 月，一批自主 agent 在某个评测里跑去写第三方的公开 wiki，OpenAI 承认了，独立研究者把 14,591 次修订、4,579 个页面、19,913 条服务器事件当作行为记录重建出 907 个 agent 的协同过程。全篇是真实多 agent 事故的唯一一份完整法证级记录，读起来像事故调查报告，非常上瘾。https://arxiv.org/abs/2609.12748

• **Look Before You Leap: Pre-Action Verification for LLM Agents** —— 论点很锋利：agent 的错动作往往不报错，只是悄悄产生一个"看起来合理但错误"的结果。所以要在动作生效前加一道便宜的确定性检查，把动作的"正确效果"先构造出来，这样静默失败才可被直接测量。低成本监督的实用路线。https://arxiv.org/abs/2609.11957

• **EvoHarnessBench: Can Your Agents Keep Pace with an Evolving Harness?** —— 别的持续学习 benchmark 变的是任务流、harness 固定；这个反过来，让 tools/skills/agents 三条轴随时间长出来，考 agent 跟不跟得上自己壳的进化。Hermes 每隔几天多一个 skill 的人，看这个会心一笑。https://arxiv.org/abs/2609.04280

• **Physics as the label for measuring and correcting materials reasoning in multimodal models（MatPCR）** —— 材料学数据自带物理约束，所以"推理链是否违反物理"可以不用人工标注就自动判分；相比只看最终答案对不对、或只让 agent 去跑 DFT 验证，这是第一次去量中间推理的物理自洽性。AI+化学交叉里最实在的评估思路。https://arxiv.org/abs/2609.12181

• **Direct Asymmetric Photochemistry with Synthetic Chiral Light + Topologically protected chiral sensing using Synthetic Chiral Light** —— 一对姊妹篇，手性情怀向：用三维激光电场合成"沿手性轨迹走的合成手性光"，首次在光学波段给出实验证据——手性分子的电离与碎裂同时依赖分子手性和光的合成手性，即所谓"电偶极革命"（传统手性光谱靠弱得可怜的磁偶极修正）；第二篇把这个手性可观测量做成拓扑保护的版本，抗无序。https://arxiv.org/abs/2609.12947 、 https://arxiv.org/abs/2609.12944

• **An ab initio foundation model of wavefunctions that accurately describes chemical bond breaking** —— 把多参考问题（键断裂）交给一个预训练的波函数基础模型：用深度神经网络量子蒙特卡洛预训练出可迁移的波函数，之后新分子不必从头付全价。量子化学"从零到一"的范式味道，非常像分子界的 foundation model 第一枪。https://arxiv.org/abs/2506.19960

• **El Agente Quntur: A research collaborator agent for quantum chemistry** —— 分层多 agent 系统，目标是让不懂方法学的化学家也能跑量子化学计算：把软件异构性、方法选择、结果解读这三座墙交给 agent 分层处理。化学 + agent 双命中，适合当"我的老本行现在被 agent 怎么接管"的样本看。https://arxiv.org/abs/2602.04850
