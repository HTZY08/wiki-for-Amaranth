• **Monroe: A Molecular Foundation Model for In-Context Probabilistic Inference** —— 把 in-context learning 做到分子基础模型上：少样本下直接做生物活性概率推断，不用重新训练，AI×化学的交集正中心，值得盯后续能不能上手玩。https://arxiv.org/abs/2608.18982v1

• **ElemCo.jl: A Julia package for electron-correlation methods** —— 开源 Julia 量子化学包，主打 Coupled Cluster / Distinguishable Cluster，宏式接口号称零 Julia 经验也能跑，还带 JLmol 可视化器——工具发布向，装来跑个水分子当消遣正好。https://arxiv.org/abs/2608.27177v1

• **Benchmarking of Fast and Interpretable UF Machine Learning Potentials** —— 给 UF³ 超快力场做 benchmark：线性回归 + 三次 B 样条基，不黑盒、跑得比主流 MLIP 快，算力和可解释性都照顾到的朴素路线，值得知道。https://arxiv.org/abs/2608.27277v1

• **The off-diagonal low rank property: new opportunities for low-scaling computational chemistry methods** —— Perspective 文：Coulomb 矩阵、密度矩阵、Fock 矩阵这些计算化学核心矩阵，基函数排好序后 off-diagonal 块天然低秩——一个性质解释一堆 O(N) 算法的底气，方法论视野向。https://arxiv.org/abs/2608.26824v1
