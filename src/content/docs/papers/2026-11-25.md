今日采集 32 篇，按兴趣筛出 7 篇值得看的。其余多是凝聚态/电子结构方法学的常规推进，跳过。

## AI Agent 做化学判断

**CASPER：用 AI Agent 自主跑多参考量子化学计算**
<https://arxiv.org/abs/2611.29902>

多参考电子结构方法能处理强关联体系，但用起来最贵的一步不是算力，是专家的判断——活性空间选多大、什么时候该换方法、键断键生成过程中电子结构变了要不要重新决策。这些判断过去只有做过很多年的老手能下。CASPER 把它拆成一条 agent 工作流，沿反应路径自主做这些决策。

对化学背景的人来说这是方法学；对搞 agent 工程的人来说，这是"把隐性专家判断显式化成可编排步骤"的一个具体样本，比泛泛谈 agent 能不能做科研要实在。

## 能上手的工具

**FastCREST：GPU 加速的 CREST 构象搜索**
<https://arxiv.org/abs/2611.28599>

一个 274 原子的镓(III)-多肽配合物，CREST 3.0.2 在 32 核上跑了 321.5 小时——三天半出一次构象搜索，大型柔性分子的常规痛点。FastCREST 没有改 CREST 的算法，只改了算法怎么用硬件：MTD 和 MD 轨迹走调优的 OpenMP 加一块 GPU，GPU 负责解 SCC 本征问题和算三体色散项，约一万五千次几何优化因此在可接受时间内完成。

这类"算法不动、执行方式重写"的工作，落地速度往往比新算法快。有 GPU 就能试。

**DICE：学生模型驱动构型探索的势函数训练**
<https://arxiv.org/abs/2611.30229>

传统两段式蒸馏的花费在第一步——用教师模型驱动构型探索，复杂材料上极贵；然后拿教师的预测去监督学生，教师错了错误会原样传下去。DICE 反了个方向：先用跑得快的学生模型加速构型探索，教师和学生交替更新，不再是一次性的单向传递。机器学习势函数开发的工程性改进，不是新物理。

## LLM 与蛋白质

**RumiFold：教通用 LLM 自己折蛋白质**
<https://arxiv.org/abs/2611.29444>

不调用外部结构模块，直接把蛋白质序列喂进 chat 模型，通过多轮"折叠"迭代从自己的隐藏状态里预测结构，再用折出来的表示回答自然语言的功能问题。结构精度做到和专门的单表征模型相当。

真正值得看的是它问的问题：学会折叠这件事本身，能不能让模型对功能的理解变好。它不是在造 AlphaFold 竞品，是在试探"折叠作为训练任务"的迁移价值。

**通用语言模型是神经符号推理者，能从序列注释蛋白功能**
<https://arxiv.org/abs/2611.28529>

领域里的默认假设是：蛋白语言模型从序列信号里学功能和结构，通用文本模型只懂符号推理、碰不了这类任务。这篇的结果相反——通用 LLM 靠符号推理完成蛋白功能注释，路径和序列模型完全不同。

这个结论对做 agent 的人有直接参考价值：专才路线（领域内大规模预训练）和通才路线（通用模型＋推理）哪个更强，这个问题不只在生物学里存在。

## 工业与物理

**PSA 装置的在线学习实时优化**
<https://arxiv.org/abs/2611.30828>

变压吸附单元的实时优化要求过程模型能在每次决策中被反复求值，严格机理模型太慢，所以走循环稳态的数据代理。代理的弱点是只在训练数据覆盖的工况下有效，没被当成输入建模的扰动它根本不知道。这篇用神经网络代理＋粒子群优化，再叠在线学习去追训练集之外的漂移。

炼厂里若涉及 PSA 制氢或氢气提纯，这是能直接对话的工业场景，不是纸面问题。

**多晶压片里用太赫兹测出磁振子手性**
<https://arxiv.org/abs/2611.30992>

手性磁振子的旋进方向，过去基本只能在单晶上测。这篇把手性螺旋磁体 CsCuCl₃ 压成一个多晶压片——晶粒的结构手性两种都有、取向全随机——在 5 到 7 T 下发现亚太赫兹磁振子对一种圆偏振的吸收比另一种强 20 倍以上。这个结果排除了"绕各自晶粒轴旋进"的解释，自旋波理论把它归到塞曼频率上。

有意思的点在制备门槛：不用长单晶，压片就能看手性响应，等于把一类测量从晶体生长实验室解放出来。手性体系里的集体激发能保留手性，这件事本身也够漂亮。
