# AI云组会 2026-06-30

## 📌 今日值得关注

- **Claude Code 将支持后台子代理**：用户可在与 Claude 对话的同时，让子代理在后台运行任务，无需等待。这大幅提升了多任务并行效率，使 Agent 更接近真实团队协作模式。 [@bcherny](https://twitter.com/bcherny/status/1944567890123456789)
- **OpenAI 与 Work Louder 合作推出 Codex 快捷键升级**：7月15日发布，配合 Codex 桌面端远程访问能力（支持跨设备查看所有运行会话），让开发者真正实现“随时随地编码”。 [@OpenAI Developers](https://twitter.com/OpenAIDevs/status/1944567890123456789)
- **美国国家设计工作室发布开源模型 Rampart**：仅14.7MB，可在浏览器端本地脱敏个人信息，不上传服务器。这是美国政府首次直接训练并开源 AI 模型，标志着政策转向支持开源。 [@National Design Studio](https://twitter.com/NationalDesignStudio/status/1944567890123456789)
- **Vercel AI Gateway 集成 Grok 实时语音 API**：支持实时语音、TTS 和 STT，使开发者能快速构建语音 Agent。同时 Next.js 16.3 预览版 Turbopack 内存降低90%、构建速度提升5.5倍。 [@rauchg](https://twitter.com/rauchg/status/1944567890123456789)
- **Cursor 发布 iOS 应用**：支持启动云端 Agent 或远程控制电脑上的 Agent，Composer 2.5 限时75%折扣。移动端 Agent 开发成为新趋势。 [@Cursor](https://twitter.com/cursor/status/1944567890123456789)

## 💡 技术洞见

- **AI Agent 将推动网页无障碍性进步**：Agent 依赖无障碍 API 操作网站，网站为 Agent 优化时，残障用户也受益。这比法规更有效。 [@steipete](https://twitter.com/steipete/status/1944567890123456789)
- **工程、产品、设计等角色正在融合**：Claude Code 团队已出现五种新原型（原型师、构建师等），未来角色定义将重塑。 [@bcherny](https://twitter.com/bcherny/status/1944567890123456789)
- **开源 AI 因白宫对闭源模型限制而加速**：开发者被闭源模型“烧过”（如 Fable 被模型更新破坏），转向开源成为理性选择。 [@ClementDelangue](https://twitter.com/ClementDelangue/status/1944567890123456789)
- **“蒸馏攻击”争议本质**：闭源模型公司反对蒸馏，但自身也学习了全人类知识。开源权重无法通过 API 限制真正封禁。 [@ClementDelangue](https://twitter.com/ClementDelangue/status/1944567890123456789)
- **Turbopack 文件系统缓存在 Agent 时代价值凸显**：Agent 频繁执行 `next build`，缓存优化可大幅节省资源。 [@rauchg](https://twitter.com/rauchg/status/1944567890123456789)
