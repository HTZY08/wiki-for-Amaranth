## 📌 今日值得关注

- **@rauchg 提出 Agentic self‑improvement**：让 agent 通过内省历史运行、发现低效与错误，自动生成新 prompt 和技能。这标志着 agent 从“执行”向“自我进化”的关键转变。
- **@steipete 转推：用图像+OCR 砍掉 ~60% Fable 成本**：将代码转为图片让模型 OCR，既野生又有效。揭示了模型处理代码时一种反直觉但极具性价比的优化路径。 [GitHub](https://github.com/teamchong/pxpipe)
- **@_catwu 展示 Claude Tag 企业级方案**：用 Claude Code + computer use 连接团队 GitHub、数据仓库、Google Drive 等，打通 agent 与企业数据孤岛。企业落地的重要示范。
- **@ClementDelangue 转推：GLM‑5.2 可直接在 Claude Code 中通过 Hugging Face 使用**：开源模型无缝嵌入主流开发工具，开发者生态进一步开放。
- **@polynoamial 评价 GPT‑5.6**：“对编码而言极其强大且快速”，希望尽快开放给所有人。Top 模型竞争白热化，速度与能力同步提升。

## 💡 技术洞见

- **Agent 自我改进是下一阶段核心**：@rauchg 强调 agent 应具备“观察自身运行 → 自动优化 prompt 与工具调用”的能力，这是从 automation 到 autonomy 的质变。
- **Loop engineering 成为新关键词**：@AndrewYNg 指出 loops（agent 的自我反思与迭代循环）已成为主流设计模式，由 Claude Code 作者 Boris Cherny 和 OpenClaw 作者 Peter Steinberger 带动。
- **让模型用自己的判断**：@simonw 分享 Fable 使用技巧——告诉模型“使用你的判断选择合适功率”，结果更高效。减少指令过载，信任模型自身的权衡能力。
- **开源模型正在重塑开发者体验**：@ClementDelangue 转推称 Qwen 27b 是“真正的英雄”，@leerob 展示 Kimi K2.7 在 Cursor 中的表现，开源与商业模型的边界快速模糊。
- **机器人技能可以无限自我叠加**：@DrJimFan 发布 ASPIRE，机器人解决第 100 个任务时不再像解决第一个那样“无经验”，技能库随时间自动演化。
