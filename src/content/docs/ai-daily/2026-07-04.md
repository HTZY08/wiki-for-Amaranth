## 🔥 今日热议

### 1. Andrew Ng 定义「Loop Engineering」为 agentic coding 新范式

Andrew Ng 发推详细拆解了「loop engineering」——这个由 Claude Code 作者 Boris Cherny 和 OpenClaw 作者 Peter Steinberger 引爆的热词。他定义了三个层级的 loop：
- **Agentic coding loop**：agent 根据 spec 写代码 → 跑 eval → 迭代，直到通过
- **Developer feedback loop**：以十分钟到小时为单位，开发者检查产品方向并给出反馈
- **Human oversight loop**：人类在关键决策点上把关

> 为什么重要：这是 vibe coding 之后的下一个关键词。从"让 AI 写代码"演进到"设计 AI 写代码的反馈回路"，标志着工程化 agent 开发的成熟度提升。

📎 https://x.com/AndrewYNg/status/2071988145667928442

### 2. Meta WhatsApp Business Agent 切换为按 token 计费

Meta 宣布自 2026 年 8 月 1 日起，WhatsApp Business 平台上的 Meta Business Agent 将从按消息计费转为按 token 消耗计费（$2/百万 token）。简单对话成本下降，复杂请求成本上升。10 月 1 日起还将恢复非模板服务消息的按条收费。

> 为什么重要：这是第一个大型社交平台将 AI agent 作为独立计费单元。1M+ 企业已使用，1B 用户每天通过 WhatsApp 与商家互动——一旦 agent 定价模型跑通，Meta 的 AI 收入将从实验性变成结构性。

📎 https://x.com/techshotsapp/status/2072987936103280822

### 3. ZCode 3.0 发布：中国厂商群起追赶 Claude Code

智谱 AI 发布 ZCode 3.0，深度集成 GLM-5.2，主打 grouped task workspaces、可视化 Git 分支图和 Goal 功能。与此同时，Pandaily 报道称阿里、字节等多家中国科技巨头都在加速开发自己的 Claude Code 竞品，形成一场"coding agent 军备竞赛"。

> 为什么重要：Claude Code 在 2025-2026 年定义了 agentic coding 的产品形态。中国大厂集体入场意味着：① 模型层的竞争正在向 agent 产品层迁移；② 开源 agent 工具体系将快速丰富。

📎 https://x.com/thePandaily/article/2072636390324474243

### 4. OpenAI GPT-5.6 Sol：750 tokens/sec 的 Cerebras 部署

OpenAI 预览 GPT-5.6 Sol，主打在 Cerebras 硬件上实现高达 750 tokens/sec 的推理速度。分三个 tier：Sol（旗舰，$5/$30 per 1M tokens）、Sol Pro、Sol Ultra。@polynoamial 评价"编码极其强大且快速"。

> 为什么重要：速度 × 质量的竞争进入新阶段。当推理速度不再是瓶颈（750 tok/s 基本消除等待感），agent 工作流的响应式体验将发生质变。

📎 https://x.com/aleabitoreddit/status/2070754658868687086

### 5. Anthropic 宣布 Claude Opus 4.7 Fast Mode 退役

Anthropic 计划于 2026 年 7 月 24 日移除 Claude Opus 4.7 的 fast mode，之后 fast 请求将返回错误。同时 Opus 4.1 的 API 退役定于 8 月 5 日。用户被引导迁移至 Claude Opus 4.8。

> 为什么重要：模型生命周期管理成为开发者必须关注的现实——依赖特定模型版本或快捷方式的团队需要制定迁移计划。

📎 https://x.com/btibor91/article/2071147905658810846

## 💡 技术洞见

**Ethan Mollick：agent 时代的数据真空**
"我们对 AI 工作影响的知识存在一个真正的断裂——2026 年实用 agent 系统的崛起导致了能力的非连续性跃迁。我们刚开始看清聊天机器人的影响图谱，但对 agents 还没有真实数据。"——这是对当前 agent 热潮最冷静的判断提醒。
📎 https://x.com/emollick/status/2044576806926512446

**Karpathy：coding 体验正在碎片化但深度化**
Karpathy 详细描述了他的 multi-workflow 编码实践：~75% 靠直接在代码里写注释/片段完成任务规格传达（比打 prompt 快得多），上层用 Claude Code/Codex 处理大块功能，Cursor 做日常。不同粒度、不同工具有不同的信号传输效率。
📎 https://x.com/karpathy/status/1959703967694545296

**DrJimFan × NVIDIA：ENPIRE — AutoResearch 首次进入物理世界**
NVIDIA GEAR 团队给 8 个 Codex agent 控制机器人舰队，配 GPUs + token 预算，目标只有一句话："以最快速度完成任务，让机器人忙起来。"结果 agent 开始自主学习看视觉线索、重置场景、练习新技能、读论文、互相讨论、反思、卡住重试——全部在真实硬件上自行完成。"我们只是给了 Codex 访问原子世界的 API，其余都是涌现。"
📎 https://x.com/DrJimFan/status/2066921736369766762

**Mistral OCR 4：结构感知文档解析超越人类基准**
Mistral 发布 OCR 4，支持 170 种语言，自带置信度评分，在文档理解任务上超过人类基准。"Agent 的生死取决于它们如何解析发票、合同和支持文档。"
📎 https://x.com/MistralAI/status/2073041314115899603

**Simon Willison 发布 Datasette Agent**
Datasette Agent 正式发布——一个可扩展的 AI 助手，连接 Datasette 数据库。这是 Simon 持续三年 LLM 工具链探索的最新产物：从 CLI 工具到 agentic 数据库查询的进化。
