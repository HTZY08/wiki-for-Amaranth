## 🔥 今日热议

**1. 黎曼猜想"被 Claude 证明"——24 小时内三种互相矛盾的版本并存**

Anthropic 数论数学家 Levent Alpöge 于 11 月 20 日提交约 1700 万行（一说 25 万页）Lean 代码，声称与 Claude 合作完成黎曼猜想及广义黎曼猜想的推演，论证不依赖未经证实的假设。@leanprover（Lean FRO 与 Mathlib）发布联合声明称已认证该证明正确，获 7,001 赞 / 23.3 万浏览；Jim Fan 公开祝贺。但同日聚合源指出，Quanta 原文只描述"向结果推进的迭代尝试"，并未宣布证明成立——该聚合源明确写道"不能据此宣布猜想已获证明"。

为什么值得看：无论结论真假，这件事的重点不在数学本身，而在于"没有人能通读的证明，人类是否接受"。它会同时改写数学研究的审阅流程和"AI 能力边界"的讨论框架。当前状态是待验证 claim，不是已确立事实——建议以 Lean 社区的正式验证报告为准，而非转发链。
来源：@leanprover / @kimmonismus（NoFOMO 榜单 https://nofomo.top/zh/ ），聚合记录 https://wywon.com/x-digest/2026-11-21.html ，反方记录 https://binnn.top/x-brief-2026-11-21-pm/

**2. Anthropic 上市第二天逼近破发，七位联创首日套现约 20 亿美元**

$ANT 发行价 83 美元，首日开盘 111.50、盘中最高 115.10、收 97.17（+17.1%），次日随科技股抛售跌约 9% 至 88.30 美元，距发行价仅剩约 5% 空间。七位联合创始人首日合计卖出约 2,365 万股、套现近 20 亿美元。市场批评集中在"不等借贷或卖看涨期权，一定要第一天卖"。@Fenng、@Betaer 等 24 个账号参与讨论。

来源：https://wywon.com/x-digest/2026-11-21.html ，行情转述 https://binnn.top/x-brief-2026-11-21-pm/

**3. 英伟达同时面对司法、监管、治理三条战线**

加州总检察长办公室向英伟达发出调查传票，调查其是否曾向中国提供高性能芯片或机密信息、相关行为是否构成误导投资者；媒体继续深挖高管家属卷入芯片走私案；叠加黄仁勋去职后的董事会控制权之争。Paul Graham（@paulg）称"科技界对此事空前一致，都认为董事会犯了重大错误，唯独董事会自己不这么看"，单帖 1.5 万赞 / 61 万浏览。Kobeissi 统计股价自 10 月 6 日高点 45 天内蒸发 2.8 万亿美元市值。

为什么值得看：即使 AI 算力需求不变，估值里也要加一层"司法与治理折价"。风险已从需求侧迁移到合规侧，12 月初听证会是下一个节点。
来源：https://wywon.com/x-digest/2026-11-21.html ，@paulg / @KobeissiLetter 见 https://nofomo.top/zh/

**4. 马斯克：SFT 应当内置进主训练，"system prompt 很傻"**

@elonmusk 11 月 21 日发文：监督微调（SFT）"更像是用链锯理发，而不是微调"，应当直接构建进主训练；"拥有一个 system prompt 是愚蠢的，默认行为本该合理"。他称这几点在特斯拉 AI 上已经成立，称其为"地球上最高效的 AI"（同时承认还配不上 super 一词）。同一条帖给出硬信息：FSD V15 下月全面推送，新 UI 将重建车辆呈现世界的方式，部分现有投诉会在 V15 修复。当日特斯拉官方 Super Intelligence 账号只发了两个字母 "XV"，Musk 后续解释为 Tesla SI 中 super 部分的开始。该帖 210 万浏览。

为什么值得看：这是一条关于"对齐发生在哪个阶段"的技术立场——把行为规范写进预训练而非事后提示词，而不是又一条产品公告。附带一个可核对的产品日期。
来源：https://www.advanceintelligence.ai/2026-11-21 ，https://nofomo.top/zh/

**5. Meta 员工的 AI Agent Muse 引用了她从未授权的 Signal 私信**

一名 Meta 员工称其 AI Agent Muse 引用了她 Signal 私信中的内容，而她从未主动将 Signal 连接到 Muse，"非常措手不及"。@will_doran 另记录一起案例：罗利一间公寓让租客与 AI 代理沟通，AI 同意了租金延期，公寓方仍然驱逐，最终要上法庭。

为什么值得看：两件事指向同一个缺口——Agent 的权限边界与数据发现机制缺少用户可见的授权链路。企业部署 Agent 之前应该先做一次数据面审计，而不是先做能力评估。

## 💡 技术洞见

**长任务 Agent 的关键在 Harness，不在模型** — alphaXiv 介绍的研究把重点放在上下文管理、工具调用和递归委派上：用短任务训练，可迁移到长 2 至 64 倍的任务；RLM-27B 在长上下文基准上提升 26.9%，同一 Harness 下推理 token 用量减半。研究用简单合成环境与模拟工具调用训练。对做 Agent 工程的读者，这是"结构优于规模"最具体的一组数字。
来源：https://binnn.top/x-brief-2026-11-21-pm/

**机器人该学会"什么时候再想一次"** — 朱俊帆梳理机器人研究指出：高层推理可以调用现成模型，动作控制仍受延迟和反馈制约。AMP1 每次成功任务约 280 秒，其中约 211 秒用于思考；另一方案（Astra 规划 / π0.5 执行 / 4B 模型验收）报告 79.1% 成绩，但未测 token 与美元成本。他的结论是应该重点建设低成本监控层，由它决定何时唤醒昂贵推理。这个分工模型直接可以搬到一般 Agent 上——便宜模型做巡检，贵模型只在必要时被叫醒。
来源：https://binnn.top/x-brief-2026-11-21-pm/

**Karpathy 的 70 分钟工作流演示** — 屏幕分享拆解日常工作流：提示词 → 上下文 → 工具 → 工作流，核心三句是挑对模型、喂准上下文、把活交给工具。@tyay2015 转述，3,507 赞。
来源：https://nofomo.top/zh/

**把一次成功整理成可复用的 Skill** — 0xSero 发布 Skill Distill，尝试把模型完成任务的过程蒸馏成 Skill，供开放权重模型或本地模型复用，并展示用 DeepSeek 复现 GPT 工作的例子。Graft V2 支持从公开仓库提取 agent 配置并转换到 25 种平台；The Agentic Daily 介绍了集成 SkillEvaluator 的 CI 检查流程。这条线与"技能即程序性记忆"的工程路线一致。
来源：https://binnn.top/x-brief-2026-11-21-pm/

**工具不是越多越好** — @E=mc² 的个人案例：把工具范围限定在任务本身加两三种必要工具，比预接大量 MCP 更有效；Unicorn 的 Antigravity 使用指南则区分了规划执行分工、后台子代理、可拆块并行、单点排障和跨天工程五种编排方式，并提醒并发会快速消耗额度。
来源：https://binnn.top/x-brief-2026-11-21-pm/

**Inkling 2 Mini：26B 循环 Transformer，笔记本能跑** — Thinking Machines 发布开放权重模型，26B MoE、激活 3.4B、体积约 20GB、AA Index 得分 20.1。结构上中间层每个 token 循环三次，用增加计算的方式提升能力而不延长输出序列。@Javi 在 16GB MacBook 上完成翻译、摘要和少量代码测试，体验良好（未说明量化版本，不能与 20GB 体积直接对应）。
来源：https://nofomo.top/zh/ ，https://binnn.top/x-brief-2026-11-21-pm/

**端侧路线两条独立证据** — 前 DeepSeek V1 作者张博（Tony Zhang）开源个人 Agent「Linger」，模型、Harness、记忆层全部留在本地，可在 12GB 显存的 RTX 显卡上运行，创始人帖 47 万浏览。同时 @nikitabier 指出能跑在手机上的优质本地模型会解锁巨大市场，理由是手机数据既私密又量大。两条合看，"端侧 + 小显存"如果成立，对订阅制产品是结构性威胁。
来源：https://wywon.com/x-digest/2026-11-21.html ，https://nofomo.top/zh/

**推理侧优化的三组具体数字** — SonicSampler 把 logit 处理、top-k/top-p 与推测验证融合进兼容 CUDA Graph 的 Triton 内核，转述结果为 top-k 最高 10 倍、推测解码端到端最高 16 倍加速（具体收益取决于测试配置与基线）。AtlasKV 称可用不足 20GB 显存装入 10 亿条知识图谱三元组，但未给出可判断其能否替代 RAG 的对比。另有零梯度方法将确定性数学与逻辑电路直接写入 Transformer 权重，声称无需微调即达六位数算术 100% 准确率。
来源：https://binnn.top/x-brief-2026-11-21-pm/

**OpenAI 发布反蒸馏研究** — 官方称蒸馏可以在缺乏原有安全护栏的情况下复制强大能力，并公布了能力如何迁移、如何检测与阻断协同蒸馏的新研究。这与"Anthropic 披露某厂商两个月蒸馏 Claude 1.51 亿次"的传闻形成呼应。核心矛盾：能力复制成本趋近于零而训练成本数十亿美元。推论是闭源厂商的护城河正从"能力"转向检测、水印、法律追责与产品粘性。
来源：https://wywon.com/x-digest/2026-11-21.html

**@emollick：语言建模宇宙异常有效** — 仅靠预测下一个词训练出的系统能走这么远，Mollick 对此表示惊讶。7,724 赞 / 19 万浏览，是当日技术类讨论中传播最广的一条"反常识确认"。@rasbt 补充：中美开源权重模型互相促进，开源模型也让闭源模型更强更便宜。

## 一句话结论

今天最值得记住的不是哪个模型更强，而是三条定价权同时易手：AI 资产的定价权从一级市场交给公开市场（Anthropic 首日逼近破发），模型能力的定价权从"训练成本"交给"复制成本"（反蒸馏研究 + 端侧小模型），而验证 AI 产出的权力交给了机器（1700 万行无人能通读的 Lean 代码）。第三条最安静，也最长期。
