## 🔥 今日热议

### 1. Claude Sonnet 5 发布：Anthropic "最 Agentic 的 Sonnet"

Anthropic 上周发布 Claude Sonnet 5，定位为"迄今为止最 agentic 的 Sonnet"——在编码、长期运行 agent、computer use 上均有大幅提升。已在 Claude Code (v2.1.197+)、Dify、Genspark 等平台上线。

- @dedene 确认在 Claude Code 中可直接 `claude --model claude-sonnet-5` 使用

- **值得关注的点：** Sonnet 系列一直被定位为"性价比最高"的实用模型，这次 Anthropic 明显在 push agent 能力。结合 Fable 5 免费额度今日截止，Anthropic 正在重新定义它的 tier 结构。

**来源：** @dedene, @dify_ai, @davidmanheim
**链接：** https://x.com/dedene/status/2072015181865972124

### 2. OpenAI GPT-5.6 Sol 在美国政府限制下有限预览

GPT-5.6 家族（Sol / Terra / Luna）于 **6月26日** 发布，但因美国政府要求额外安全审查，仅以 limited preview 形式上线。Sol 为旗舰模型，带 "ultra mode" 用于子 agent 编排；Terra 均衡任务；Luna 低成本高吞吐。

- Cerebras 宣布将在 7 月以 **750 tokens/s** 的推理速度运行 Sol 模型（先对 select customers）
- @TraffAlex 报道 OpenAI 同时将 IPO 推迟到 2027 年
- 这是首个因政府干预而限制发布的 OpenAI 旗舰模型——标志性事件

**来源：** @TraffAlex, @karlmehta, @gpmt
**链接：** https://x.com/TraffAlex/status/2070856266969186729

### 3. #Keep4o 运动：用户要求 OpenAI 保留并开源 GPT-4o

OpenAI 去年退役 GPT-4o 后，社区发起了 **#Keep4o #BringBack4o #OpenSource4o** 运动，已经有数百条帖子。核心诉求：GPT-4o 是"唯一真正令人惊叹的模型"，后续模型在情感质量和用户体验上不如 4o。甚至有用户向联合国提交政策倡议。

- 趋势标签 #Keep4o 持续在 X 上活跃

- 本质上是用户对"模型能力提升但可用性/情感连接下降"的集体反弹

**来源：** @keepgpt4o, X trending
**链接：** https://x.com/keepgpt4o

### 4. DeepSeek V4 发布 DSpark 推理优化：85% 加速，零质量损失

梁文锋（DeepSeek 创始人）发表了公司危机后的 **首篇论文**——DSpark，一种半并行投机解码系统，让 DeepSeek V4 在匹配吞吐量下实现每用户 **60-85% 的生成加速**。

- 核心创新：不是 draft 更多 token，而是选择性验证——先 draft 一个 block，评分每个 prefix 的存活概率，只验证可能值得付费的部分
- @rohanpaul_ai 详细解读：小 Markov head 调整每个猜测，解决纯并行 draft 的"后段 token 衰退"问题
- Pandaily 报道称这是 DeepSeek 历劫归来后的第一张成绩单

**来源：** @rohanpaul_ai, thePandaily, @iam_elias1
**链接：** https://x.com/rohanpaul_ai/status/2070936676915147143

## 💡 技术洞见

### 1.  "Scaffold Effect in Coding Agents" — ICML 2026 论文揭示 benchmark 噪音
@navreeetkaur 和 @gneubig 在 ACL 2026 和 ICML 2026 上讨论了一个关键发现：**Agent benchmarks 对 scaffold（脚手架）极其敏感**。相同的模型，换不同的 agent 框架/编排方式，结果天差地别。这意味着：
- 模型排名中有大量"scaffold 噪音"
- Agent 能力评测必须标准化 scaffold 才可比较
- "训练-循环" benchmark 天然昂贵，评测正在从静态数据集转向真实工作流

**来源：** @gneubig, @navreeetkaur
**链接：** https://x.com/gneubig/with_replies

### 2. Fable 5 编排模式：规划+审查+执行三层架构
@PrajwalTomar_ 分享了 Fable 5 的最佳实践：把完整 playbook 喂给 Claude Code，让它自动配置 **Fable 5 做规划+审查、Sonnet 5 做执行** 的 orchestrator 模式。今天（7月7日）Fable 5 免费额度截止后，这个分层策略能最大化 credit 利用率——用便宜的 Sonnet 跑执行，Fable 5 只做关键判断。

"文章的用途变了——不再是人类读的内容，而是 agent 替你执行的 playbook。"

**来源：** @PrajwalTomar_
**链接：** https://x.com/PrajwalTomar_/status/2073384329758363798

### 3. GLM-5.2：中国开源模型逼近前沿，成本仅为 1/6
智谱 GLM-5.2（753B MoE，~40B active）以 MIT 许可开源。@zerokn0wledge_ 的测评数据：
- SWE-bench Pro: 62.1（超越 GPT-5.5，与 Opus 4.8 差 1 分）
- FrontierSWE: 仅落后 Opus 4.8 1 分
- 成本约为 Opus 4.8 的 **1/6**
- LLM Stats Index 排名 **#3**

这是中国开源模型首次在编码 agent benchmark 上系统性逼近闭源前沿，且价格优势显著。

**来源：** @LLMStats, @zerokn0wledge_, @ClementDelangue
**链接：** https://x.com/LlmStats

### 4. ASPIRE：机器人技能库的自我进化
NVIDIA 的 @DrJimFan 和 @jeffclune 发布了 ASPIRE 项目——一个能自我进化、无限复合的机器人技能库。核心思想：让机器人解决第 100 个任务时不再像解决第 1 个任务一样陌生。每次成功执行的经验会被编码为可复用技能，技能之间可以组合，形成正反馈循环。

这是从"训一个模型解决一个任务"到"模型+技能库自进化"的 paradigm shift。

**来源：** @jeffclune, @DrJimFan
**链接：** https://x.com/jeffclune/status/2072342393706479823
