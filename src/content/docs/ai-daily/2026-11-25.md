### 1. Claude Ship：AI 开始批准自己的 PR

@ClaudeDevs 11-24 04:13（北京时间）发布 Claude Ship beta：Claude 能审 PR、动手改失败项、并按团队策略自动批准合规的改动。360 万浏览、2.5 万赞，是这个窗口内互动量最高的英文 AI 公告。

为什么值得看：这是把 code review 这个环节也交出去了。以前是"AI 写、人审"，现在审批动作本身被策略文件接管——人类剩下的位置从"逐条看 diff"变成"写策略、跑 observe 模式看它批得对不对"。@noahzweben（Claude Code PM）的说法很直白：这东西存在的意义是吸收 coding 工具自己制造出来的巨量 PR 吞吐，否则 review 环节会被压垮。

内部实测口径（来自官方 trending 摘要，非独立验证）：合并 PR 数翻倍以上，回退率降 40%+。计费按 token，仅 GitHub 上的 Team / Enterprise 计划。

有反对声。@fekdaoui 的质疑拿到 11 万浏览："这跟直接让 Claude review 我的 PR 有什么区别？"这个问题目前没看到官方正面回答。

### 2. GLM-5.4：用"循环"换深度，第一次进旗舰

@Zai_org 11-23 18:27 发布 GLM-5.4，自称首个 Loop Transformer 旗舰。做法不是从头训一个循环模型，而是把已经预训好的 GLM-5 基座接着训成循环结构：28 层中间层在同一 token 上跑两遍、共享权重，750B 规模。官方口径"智能水平对标 2T–3T 参数模型"。

省显存的手法值得单独记：第二遍直接复用第一遍产出的稀疏 KV 和 attention 索引，自己只多一个 128 token 的滑动窗口——所以在 1M 上下文下，多跑一遍几乎不额外吃显存。第一遍保守写回、第二遍才全量更新，靠 per-token gate 控制。

社区拆解（@sophiamyang）：官方至今没放 benchmark 表，唯一可查的是 30B 等比对照——同参数、只多约 10% 训练算力，AIME25 从 19.2 涨到 30.4，GPQA-Diamond 从 47.6 涨到 56.3，同时答案短了 10–15%。也就是说一部分推理从显式输出 token 挪进了隐式循环深度里。

@tphuang 的判断更结构化：GLM-5.4 真正的意义是验证了 Loop 这个"旋钮"有效，Z.ai 会把它套到 1B / 4B / 30B 以及后面那个更大的旗舰上。对比 Moonshot，他认为智谱的 RL pipeline 一直更硬。

代价也清楚：中文社区转述的 KingBench 4 个人榜单里，GLM-5.4 拿 55.3%（33.2/60），19 个模型排第 7、开源第一，但一次 Max effort 跑完用了 431 分钟、104 万 reasoning token、1128 步——同期 Gemini 4 Neon 只要 109 分钟和约 7 万 token。官方自己也承认模型容易陷进"马拉松式思考"。

### 3. DeepMind 用 Gemini 4 agent 团队重写量子电路，但"290 倍"是被吹出来的

@GoogleDeepMind 11-24 01:00 发布：用 Gemini 4 agent 组成的多支独立队伍，设计出把未来仿真成本最多降到 1/10 的新量子电路，瞄准聚变、化学、药物发现。30 万浏览。

工程方法比结果更值得抄：每道题分给互相独立的 agent 队伍，候选电路必须通过 Lean 形式化证明才能进共享 notebook，各队每 4 小时开一次虚拟会议交换、辩论想法。Lean 库和验证过的解已开源。这是"用形式化证明给 AI 搜索打分"的实打实例。

数字要按范围读，这点被转述搞乱了：官方口径是"最高 10 倍"，具体条目里惯性约束聚变电路 11.8 倍、光敏分子光化学仿真 8 倍、细胞色素 P450 2.5 倍（纠错量子比特从 481 降到 333）、Grover 某实现 2.57 倍。至于疯传的 290 倍，只属于把数字装进量子态的 arcsin 子程序，不是整体仿真成本。官方博客自己还补了一句：即便有这些改进，跑真实科学仿真仍超出早期纠错量子计算机的能力。

@fchollet 的评论切中要害："仿真成本降 10 倍基本等于一次硬件跃迁。"

### 4. Shirudo：让 agent 写 eBPF 盾牌，不停机挡漏洞

@OpenAI 11-24 05:37 宣布与 Cisco 联合开源 Shirudo——一个 Linux runtime，让 agent 在发现漏洞的当下写出动态 eBPF 控制，把攻击挡在系统外，给防守方争取测试和推补丁的时间。206 万浏览、1.79 万赞，本窗口第二大。

机制上做对了两件事：一是先观察这面盾牌会对应用造成什么影响，再由人批准部署——"自动防御"仍然卡在人类批准之后；二是每面盾牌密码学签名后才加载，eBPF verifier 按内核安全规则校验程序，内核安全控制限制未授权改动，TPM 可留可验证的加载/移除记录。主项目 BSD 2-Clause，BPF 程序 BSD/GPL 双许可。真实测试目前只有一个场景：Codex 生成的盾牌给 Java Base64 解码器加输入检查，直接挂到运行中的 Elasticsearch 进程上，Java4Shell 攻击被拒，服务没重启。

@stretchcloud 点出了没人定价的那部分风险：一个 agent 写的、不重启就进内核的补丁，离"一次坏盾牌造成和漏洞同等规模的故障"只差一步。Shirudo 的答案是证据门控加密码学签名，而不是承诺——思路对，但只有足够多的人拿真实流量跑并报告哪里坏了，这东西才立得住。

- Brockman 转发：https://x.com/gdb/status/2124985602722676794
- 风险讨论：https://x.com/stretchcloud/status/2125011513962369357

### 5. Claude 把 connectors 和 skills 合成 plugins，一上来就是 1 万个

@claudeai 11-24 04:56：连接工具和教它一个新技能，现在合成一件事叫 plugins，页面只有一个 claude.ai/plugins。Free / Pro / Max / Ultra 今天上线，Team / Enterprise "即将"。上线即有 1 万+ 插件可浏览，94 万浏览。

为什么值得看：插件数从零到一万不是自然增长——是把既有 connectors 和 skills 库存直接并表。真正变的是心智模型：以前"接一个 API"和"教一套流程"是两件事，现在是一次安装。对企业侧更实际的影响在 11-30 之后——按 Anthropic 的规划，届时 Skills 开关改名为 Plugins，关掉 Skills 会连带阻断插件。

同一批发布里还有一件事没被充分讨论：@askalphaxiv 转述 Anthropic 内部一个 Claude 模型署名了一篇 70 页论文，内容是 Valiant 猜想（P vs NP 的代数近亲）的证明，Lean 证明通过自动校验。26 万浏览，但人类专家复核尚未完成——只能当"AI 推理走到哪了"的信号，不能当结论。

**Karpathy：提示词正在消失，留下的是图。** 一段一小时讲座被 @ai_explorer25 提炼成一句："Prompting is fading away. Delete everything else and keep the graph." 他给的演化线是 LLMs → Prompts → Agents → Graphs，并认为大多数人还在死磕提示词，而图才是最后活下来的那层。同一个人 11-08 的说法是：与其逼 agent 做更多，不如把 harness engineering 和环境搭对——"有时候真正的突破不是更好的 agent，是模型周围更好的系统"。

**开源权重成了地缘议题，而且是从 CEO 嘴里说出来的。** @amasad（Replit CEO）11-24 07:29 发帖谈与副总统 Vance 的会面，落到一句很重的话：盟友想要主权 AI，越来越多地在看中国开源模型；而美国创业公司需要有竞争力的模型生态——"美国可能赢了前沿竞赛，却输掉全球 AI 生态"。34.7 万浏览。这话放在 GLM-5.4 同一天刷屏的背景下读，不是巧合。
https://x.com/amasad/status/2125008810041610359

**"能跑"和"能批"是两件事，@fekdaoui 那一问值得所有做 agent 的人抄下来。** Claude Ship 发布后最高赞的质疑就是"这跟我直接让它 review 有啥区别"。这类追问的价值在于把发布文案里的动词拆开：review 是生成，approve 是承担后果。前者模型早就能做，后者需要策略文件、observe 模式、分支保护这些非模型的东西。区别不在模型，在责任边界怎么划。
https://x.com/fekdaoui/status/2124971043567636746

**过度思考是有账单的。** GLM-5.4 那次 Max effort 跑到 431 分钟 / 104 万 reasoning token，同期对手 109 分钟 / 7 万 token——完成质量未必差多少，成本差一个数量级。同一个模型的 High 和 Max 档在安全测试里因为想太久直接撞 180 秒超时，Medium 档 95 秒就交卷。结论不是"别用高档"，是同一模型的不同 effort 档该按任务类型分开配，当 code reviewer 和当全能选手的性价比根本不在一条线上。
https://aitimeline.news/en/Daily/2026-11-24-X%E6%97%A5%E6%8A%A5/

**形式化证明正在变成 AI 产出的过滤器。** 这轮最扎实的两件事——DeepMind 的量子电路和那个 Valiant 猜想证明——共同点是都过了 Lean。不是"模型说它对"，是"机器能验它对"。这比任何 benchmark 分数都硬，因为它不像 benchmark 那样会被训练数据污染。
https://x.com/GoogleDeepMind/status/2124911073266413634
