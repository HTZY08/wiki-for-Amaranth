## 6月关键趋势

1. **模型地缘政治化：** 美国首次对商业 AI 模型实施出口管制，Fable 5 从发布到被封 3 天
2. **开源黄金窗口：** Fable 5 被封 → GLM 5.2 / Nemotron 3 填补，开源模型在 agent 场景首次成为严肃选项
3. **硬件垂直整合：** OpenAI 自研芯片 Jalapeño、Etched 推理芯片流片、成本结构正在被重写
4. **Loop Engineering 取代 Prompt Engineering：** 从"写 prompt"到"设计 agent 循环"
5. **多模型编排成为新范式：** OpenRouter Fusion、Sakana Fugu——组合系统替代单一模型
6. **Agent > Chat：** OpenAI 内部 agent 使用量 13x 增长，Karpathy 称"编程已变"
