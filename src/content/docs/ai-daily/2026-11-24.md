**2. OpenAI 开源 Shirudo：让 Agent 写 eBPF 规则给系统打补丁**

@OpenAI 发布 Shirudo，一个面向 agentic 时代的开源 Linux 运行时，由 @cisco 参与构建。核心机制是让 Agent 动态编写 eBPF 控制程序，在漏洞爆发到补丁铺开的窗口期里把系统先护住，从而给防守方争取测试与灰度的时间。@gdb 转帖定调：\"给防守方以机器速度防御的能力，不用停机。\"

为什么值得看：这是把 Agent 从\"替你写代码\"推到\"在运行时改内核行为\"的一步，也是安全侧第一次把 Agent 放在防守位而不是攻击位。风险随之而来：eBPF 程序跑在内核里，写错一行就是全机崩溃，而写它的是个概率模型。这条的真正门槛不在模型能力，在沙箱与回滚机制。

来源：https://aidaily.fyi/en/s/voices （@OpenAI 帖 2.3K 赞 / 236 转，@gdb 转帖）

**3. 智谱发布 GLM-5.4：首个 loop transformer，代码之外还打 3D 与 CAD**

@Zai_org 发布 GLM-5.4，在 GLM-5 基座上循环复用已有层来做更深的推理，同时加入视觉能力，明确把目标从\"写代码\"扩到视频、游戏、3D shader 和 CAD 建模。GLM Coding Plan 订阅用户已可使用，@ZixuanLi_ 补充周配额比 GLM-5.3 高 50%；API 访问要等安全评估，权重承诺后续发布。@aicodeking 把它放在 KingBench 4 第 7 位——开源模型最高位，评价是\"谨慎但比 Gemini 4 Neon 在 Max 档慢约 4 倍\"。@bindureddy：\"GLM 一直是便宜的编码替代品，开源仍在蓬勃生长。\"

为什么值得看：loop transformer 是个信号——当堆参数和堆数据的边际收益变薄，把层循环起来换推理深度成了新的性价比路线，@natolambert 同一时间也在说\"循环架构是第一步\"。对预算敏感的人是实打实的好消息：开源模型第一次在\"深度推理\"这个维度上找架构级解法，而不是靠蒸馏闭源模型。

来源：https://www.bam.dog/pulse （On — Nov 23，X-led 头条）

**5. Anthropic 上市三天，债券先被判了垃圾级**

@WSJ：Anthropic 至今未盈利、成立不足六年，债券市场预期评级机构会把它评为投机级（垃圾级），因为投资人不确信它能否履行长期义务。这条与上周\"IPO 募资 810 亿美元、现金 2,370 亿创纪录\"形成刺眼对比——股权端抢着给钱，债权端要求垃圾级利差。

为什么值得看：两个市场对同一家公司定价分歧这么大，说明分歧点在\"这笔钱能烧多久\"而不是\"技术行不行\"。IPO 是一次性融资，而训练成本是持续现金流；垃圾级评级直接抬高后续举债成本，这决定了 Anthropic 明年的模型节奏是被迫放缓还是继续堆。

## 💡 技术洞见

**@amasad：Agent 集群的 scaling law 与传统 scaling law 不是一回事**

\"Replit 关于 agent swarm 的新研究：放大 agent 数量能带来显著性能提升，但与传统 scaling law 不同，更多算力不一定转化为更好结果，关键在于 agent 怎么组织。\"这句话的技术含量在于否掉了\"堆 agent 就变强\"的直觉——多 agent 的瓶颈在协调开销与错误累积，一旦编排结构不对，加 agent 等于加噪声。对正在搭多花架构的人是直接提醒：先定协议再扩编制。

来源：https://aidaily.fyi/en/s/voices

**@fchollet：所有智能系统只有两个适应时间尺度**

\"我见过的所有智能系统恰好有两个适应时间尺度。第一个是即时的情境建模，在人类身上叫流体智力，在现代 AI 里通过推理链生成或程序生成实现。\"第二个他没展开，但从上下文看是跨任务的学习/权重更新。这条的价值是把\"推理链\"定位成一个具体的工程构件而不是玄学——它替代的是人类的即时适应能力，所以它天然不可解释、也不该被要求可解释。

来源：https://aidaily.fyi/en/s/voices

**@natolambert：可解释的思维链注定要消失**

\"可解释的 CoT 会消失，这是优化的必然路径。它之所以可读，是我们最初发现推理期计算方式（与上下文学习有关）时留下的低效。\"他进一步点出 looped 架构是第一步——一旦模型在隐空间里循环，中间态就不再是自然语言。这条和上面 GLM-5.4 的 loop transformer 是同一天的两个侧面：行业正在主动放弃\"能读懂的推理\"，换取更深的计算。对审计与安全监控是个长线坏消息。

来源：https://aidaily.fyi/en/s/voices

**自我纠错样本：Pliny 撤回 Inkling 2 Mini「词汇手术」主要结论**

Pliny 先声称只改几行 embedding/unembedding 权重（把拒绝 token 推向顺从 token）就能把 Inkling 2 Mini 的拒绝率压到近零。几小时后他发更正：chat template 里残留的一个 prefill 干了大部分活，所以 97.4% 的顺从率不能算这个方法的干净结果。这条之所以值得记：X 上这类\"越狱新方法\"从发布到传播再到撤回通常不超过一天，而撤回的传播量远小于原帖——看到这类结论时，等 24 小时再引用。

来源：https://www.bam.dog/pulse
