# AI云组会 2026-07-14 星期二

> 本简报基于 X/Twitter 上 AI 前沿账号的公开讨论，采集时段覆盖 7/11-7/14。

---

## 🔥 今日热议

**1. GPT-Live 全量推送：OpenAI 新一代语音模型上线**

OpenAI 于 7 月 13 日正式向所有 ChatGPT 用户（Go/Plus/Pro 计划）推送 GPT-Live——新一代全双工语音模型，支持实时听与说。GPT-Live 可同时接收和生成语音，不再是"你说一句我等一句"的交互模式，还能在后台将复杂问题委托给 GPT-5.6 等前沿模型处理。这标志着 AI 语音交互从"对讲机模式"进化到了"真人对话模式"。
→ [@OpenAI 推文](https://x.com/OpenAI/status/2074907025537224840)

**2. Grok 4.5 发布：专为编码和 Agent 训练的 Opus 级模型**

SpaceXAI 于 7 月 8 日发布 Grok 4.5，这是其首个专门针对编码和 agent 执行训练的模型。与 Cursor 联合训练，定价 $2/$6 每百万 token（输入/输出），约为 Opus 级模型的 1/10。已在 Cursor 中作为"High Fast"选项上线，社区反馈是"把 Opus 级编码成本降到可以随便用的程度"。有开发者已基于 Claude Fable 5 + Grok 4.5 搭建了开源编排方案。
→ [@RKepplinger3d](https://x.com/RKepplinger3d) | [@mikenevermiss](https://x.com/mikenevermiss/status/2075721193336787186) | [@billyuchenlin](https://x.com/billyuchenlin/highlights)

**3. GPT-5.6 Sol Ultra：并行测试时计算破解 50 年数学猜想**

Noam Brown (@polynoamial) 透露 GPT-5.6 Sol Ultra 通过并行测试时计算（parallel ttc），将解决一个 50 年未解数学猜想的时间从数天压缩到数小时。这是并行推理在数学证明领域的首个成功案例——传统推理受限于串行延迟，而 Sol Ultra 将数周的计算并行化到可接受时间窗口。模型现已公开可用。
→ [@polynoamial](https://x.com/polynoamial) | [@OpenAI](https://x.com/OpenAI)

**4. Claude Code 桌面端内置浏览器：AI 自己上网了**

Anthropic 为 Claude Code 桌面应用添加了内置浏览器——Claude 可以自己打开网站、阅读文档、点击交互，无需用户复制 URL。沙盒化、可配置会话持久化。社区反应强烈："浏览器将成为 AI agent 的工具，人不再需要打开它。"
→ [@_catwu](https://x.com/_catwu/status/2075647324790112304) | [@ClaudeDevs](https://x.com/ClaudeDevs/status/2075635283211772279) | [@VaibhavSisinty](https://x.com/VaibhavSisinty/status/2075655300766679191)

**5. Nous Hermes Agent 预装到 rabbitOS**

Nous Research 宣布 Hermes Agent 现预装在 rabbit R1 设备上。用户开箱即可通过语音与 Hermes 交互执行任务。同时 Hermes Desktop 支持自动发现并连接云端 agent 实例。开源 agent 首次以预装形式出现在消费级硬件上。
→ [@NousResearch](https://x.com/NousResearch) | [@philip0x](https://x.com/philip0x)

## 💡 技术洞见

**"Let the model cook"—让模型自己发挥**
Peter Yang 在播客中与 @imjaredz 讨论一个反直觉的经验：当模型能力提升，第一件事是删除过度指令，让模型自己"cook"而不是推着它走。这反映了一个正在形成的共识——好的 agent 设计不是靠更精细的提示词，而是靠给模型留出发挥空间。
→ [@petergyang](https://x.com/petergyang)

**Morpheus：面向持续学习的全新 benchamrk**
François Chollet 发布 Morpheus，一个持续学习场景的 benchmark。与传统 episodic 基准不同，Morpheus 提供持久仿真环境——世界从不重置、目标持续漂移、模型必须不断适应。这更贴近真实部署场景，也是对"一次性学习→上线→不动"范式的挑战。
→ [@fchollet](https://x.com/fchollet)

**"优雅的失败"比绝对正确更重要**
同样是 @fchollet 的观点：尝试、失败、更新心智模型的过程才是智能的核心。应该奖励能快速适应而非一开始就正确的模型。这呼应了 ARC-AGI 的设计哲学——不是考记忆力，是考适应力。
→ [@fchollet](https://x.com/fchollet)

**ASPIRE：机器人的技能库可以自进化**
NVIDIA GEAR 实验室的 ASPIRE 框架让机器人拥有自进化的技能库——机器人完成第 100 个任务时不再是新手。代码 agent 的经验累积机制首次被系统性地复制到物理机器人领域，零样本在 LIBERO-Pro 长任务上达到 31%。
→ [@DrJimFan](https://x.com/DrJimFan/highlights) | [@guanzhi_wang](https://x.com/guanzhi_wang)

**Smart Cellular Bricks：无中央控制的物理集体智能**
Sakana AI 的论文被 Nature Communications 接收并将在 ICML 2026 展示。物理模块在没有中心控制的情况下能自识别形状、自修复。这是超越 LLM agent 的研究方向——从自然界复制集体智能机制到物理世界。
→ [@hardmaru](https://x.com/hardmaru)

**降低推理成本是 agent 普及的隐藏杠杆**
每次模型降价都解锁新的用例。Grok 4.5 把 Opus 级编码成本降到 1/10，可能比任何架构创新都更能推动 agent 采用——经济性决定普及速度。
→ [@levie](https://x.com/levie) | [@RKepplinger3d](https://x.com/RKepplinger3d)
