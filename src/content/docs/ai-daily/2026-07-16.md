# AI云组会 2026-07-16 星期四

## 🔥 今日热议

1. **Thinking Machines Lab 发布首个开源模型 Inkling（975B MoE）**
   - 做了什么：前 OpenAI CTO 创立的 Thinking Machines Lab 发布首个开放权重模型 Inkling，975B 总参数/41B 激活的 MoE 架构，1M token 上下文窗口，原生支持文本/图像/音频多模态，45T tokens 预训练，Apache-2.0 协议。
   - 基准成绩：AIME 2026 97.1%、GPQA Diamond 87.9%、SWE-bench Verified 77.6%、Terminal-Bench 2.1 63.8%。
   - Databricks 同日宣布通过 Unity AI Gateway 提供 Inkling 接入（day zero launch）。
   - 为什么值得看：填补了开源前沿多模态模型的重要空白，基准表现超越 Nemotron 系列，且完全开放权重。
   - 来源：@thinkymachines / @ChrissGPT / @steipete / @Databricks
   - 链接：https://x.com/ChrissGPT/status/2077460791234580788

2. **NVIDIA GEAR 实验室的机器人模型达到 8000 步上下文（5 分钟肌肉记忆）**
   - 做了什么：Jim Fan (@DrJimFan) 宣布将机器人模型原生扩展到 8000 timesteps 的上下文窗口，相当于 5 分钟的肌肉记忆长度，且推理成本保持恒定。关键技术是 Test-Time Training（TTT）。
   - 为什么值得看：机器人策略此前受限于逐帧决策的短视窗口，长时程上下文使机器人可以执行连续操作序列——从"看到什么做什么"转向"有记忆地自主执行"。
   - 来源：@DrJimFan / @chris_j_paxton
   - 链接：https://x.com/DrJimFan（约 6 小时前发布）

3. **GPT-5.6 Sol Ultra 以 64 子代理并行推演证明 Cycle Double Cover Conjecture（50 年未解数学猜想）**
   - 做了什么：Noam Brown (@polynoamial) 披露 GPT-5.6 Sol Ultra 使用 64 个子代理并行搜索，在不到一小时内产出了 Cycle Double Cover Conjecture 的证明。模型已公开发布。
   - 为什么值得看：这不是自动解题，而是 AI 真正产出新科学知识的里程碑——从"解已知问题"到"生成全新数学知识"的跃迁。注意该猜想是 Cycle Double Cover Conjecture，**不是** Erdős 单位距离问题（部分简报出现了实体替换错误）。
   - 来源：@polynoamial（Noam Brown），7月10日发布，本周持续引发讨论
   - 链接：https://x.com/polynoamial/status/2075646048425431469

4. **DeepSeek 发布 DSpark 投机解码，吞吐量提升 51%-400%**
   - 做了什么：DeepSeek 为 V4 Flash 和 V4 Pro 发布 DSpark 投机解码方法，大幅提升推理吞吐。在高并发场景下，DSpark 在吞吐量/延迟权衡上优于 MTP 和非投机解码方案。
   - 为什么值得看：推理效率直接决定 Agent 产品的经济性——更低的 token 消耗意味着长周期 Agent 任务的单位经济学显著改善。
   - 来源：@Oasis_a19 / @danielhanchen / @lmsysorg
   - 链接：https://x.com/Oasis_a19

## 💡 技术洞见

- **"Agentic coding 工具已跨越 800 万活跃用户"** — Tibo Sottiaux（OpenAI 工程负责人）
  Codex 与 ChatGPT Work 合并活跃用户突破 800 万。从 2 月的不到 100 万到 7 月的 800 万，证明 agentic coding 正从专家工具转向默认基础设施。这一数字的增速（5 个月 8x）可能比任何定性分析都更能说明行业拐点。
  来源：@NeoAIForecast 每日回顾 / @RonnieChatterji
  链接：https://x.com/NeoAIForecast/article/2077337387127001215

- **"你完全理解代码逻辑时，打字是纯体力活——AI 替你干更快"** — simonw
  当开发者已经理解自己要做什么、代码结构是什么时，从思路到实现之间的"打字"环节变成了纯机械劳动。AI 编码工具恰好卡在这个位置，让熟手开发者效率翻倍。
  来源：@simonw

- **"循环工程（Loop Engineering）是 agentic coding 的核心范式"** — Andrew Ng
  Loops 已从 Boris Cherny（Claude Code）和 Peter Steinberger（OpenClaw）的实践语汇变成行业热词。核心思想：不再写完整的 prompt，而是设计 agent 自主迭代的循环——规范的 agentic coding loop、developer feedback loop、product evaluation loop，三种循环嵌套构成现代 AI 开发的执行框架。
  来源：@AndrewYNg
  链接：https://x.com/AndrewYNg/status/2071988145667928442

- **Prime Intellect：不做基础模型，靠后训练基础设施做到 $100M ARR**
  Prime Intellect 在不到 12 个月内从零做到 $100M ARR，$130M Series A（Radical Ventures 领投，NVIDIA/Intel/Dell 跟投）。核心洞察：OpenAI 和 Anthropic 锁定了 RL/post-training 循环，企业无法自定义微调自有模型。Prime Intellect 填补了这个空白（prime-rl 分布式 RL 训练、Verifiers v1 环境分解、2500+ 社区 RL 环境库）。
  来源：@stretchcloud / @guilleflorvs
  链接：https://x.com/stretchcloud/status/2076559752637874484
