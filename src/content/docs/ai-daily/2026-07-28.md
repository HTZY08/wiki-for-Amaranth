### 1. Kimi K3 开放权重：史上最大开源模型 2.8T 参数落地

### 2. Claude 共享对话泄漏：隐私数据被 Google 索引

7/27 周末，Reddit 用户发现通过 `site:claude.ai/share` Google 搜索操作符可检索到大量 Claude 共享链接。TechCrunch 报道称其中包含医疗记录、临床试验患者姓名、公司内部文件、儿童姓名和电话号码。

Anthropic 回应称共享链接只有在被发布到公开论坛或社交媒体时才会被搜索引擎索引，私下发送的链接不可搜索。截至周一午后，Google 搜索结果已被清除。

Futurism 报道发现了一份详细的患者医疗报告。Fortune 报道称一条标注"shared by Anthropic"的对话包含 Claude 生成的色情内容。

### 3. Claude Opus 5 在 ARC-AGI-3 上跑出 30.2%，碾压 GPT-5.6 Sol 四倍

ARC Prize 团队公布，Anthropic Claude Opus 5 在 ARC-AGI-3 基准测试上得分 30.2%，相比 OpenAI GPT-5.6 Sol (Max) 的 7.8% 记录领先近 4 倍。Opus 5 还解决了 5 个此前未解的环境，其中 4 个达到或超过人类水平。

ARC Prize 分析将领先归结于更强的逻辑推理能力——测试过程中 Opus 5 展示了模型此前未出现的行为：自主将任务翻译为代数符号表达，独立构建反射方程。在旧版 ARC-AGI-2 上得分为 90.4%，ARC-AGI-1 上达 97.5%。

独立测试（Witness 基准）显示增益更窄，表明 ARC-AGI-3 的突破可能部分来自针对性的训练数据标注和 RL 优化。

## 💡 技术洞见

### 4. Karpathy：Agent 热潮是在重蹈 OpenAI 五年的弯路

Andrej Karpathy 在一次分享中提出三阶框架：① 停止强行让 agent 做所有事，先理解底层模型；② Demo 容易，产品需要十年；③ Agent 不是产品，基础模型才是核心，基础扎实后 agent 会自然涌现。

他指出 2016 年 OpenAI 试图用强化学习构建 agent 做订机票和点餐，项目完全失败，浪费了五年时间才转向语言模型。"当时唯一的锤子是强化学习，正确的做法是完全忘掉 agent，把所有精力集中在构建语言模型上。"

Karpathy 还给出了对竞争格局的判断：当一篇新 agent 论文发表时，大实验室的团队也觉得眼前一亮——因为他们也没有在这个细分方向上秘密研发五年。这意味着巨头必须与草根创业者和黑客在同一起跑线上竞争。

📎 [NewClawTimes — Karpathy Says Agent Hype Risks Repeating OpenAI's Five-Year Detour](https://newclawtimes.com/articles/karpathy-foundation-models-agent-hype-openai-five-year-detour/)

### 5. Induction Labs Photon-1：看 18 年屏幕录像学会用电脑，算力仅 Gemini 的 1/30

Induction Labs 发布 Photon-1——首个"想象模型"（imagination model）。106B 参数稀疏 MoE 架构（5B 激活参数），在 5.75 亿帧屏幕录像（≈18 年视频，1fps 采样）上自监督预训练。训练仅需约 30,000 H200 GPU-hours。

核心创新：模型不是预测下一个 token 或生成像素，而是在潜在表示空间中以 next-latent-token 方式自回归预测未来帧。每帧压缩为 960 个离散 token（仅 2.2KB），比 OCR + 多模态表示小约 100 倍。

@induction_labs 在 X 上宣布："We're introducing imagination models: a new foundation model architecture that unlocks learning from internet-scale video."

据称在内部计算机使用基准上超越 Google Gemini 3.1 Flash-Lite，算力仅其 1/30，推理成本低 3 倍（$0.11/M token vs $0.36/M token）。但基准为内部未公开，需独立验证。

📎 [Metaverse Post — At 30× Less Compute, Induction Labs' 'Imagination Model' Outperforms Google By Watching](https://mpost.io/at-30x-less-compute-induction-labs-imagination-model-outperforms-google-by-watching/)
📎 [@induction_labs on X](https://x.com/induction_labs)
