# AI云组会 2026-07-09 星期四

## 🔥 今日热议

### 1. GPT-5.6 Sol/Terra/Luna 全球公开发布 — AI 史上最重磅的发布日之一

OpenAI 在 7月8日获得美国政府批准后，7月9日正式向全球推出 **GPT-5.6 三档模型家族**。这是继 GPT-5.5 之后最大幅度的能力跃升，也是 OpenAI 首次采用天体命名体系。

三档配置：
- **Sol（太阳·旗舰）**：$5/$30/百万token，面向深度 agent 推理。在 ExploitBench 上用 Mythos 5 80% 的 token 出更优结果。KingBench 3 得分 78.57%，Terminal-Bench 2.1 上大幅领先 GPT-5.5
- **Terra（地球·平衡）**：$2.5/$15，成本仅为 GPT-5.5 一半，但性能接近 GPT-5.5 水平。KingBench 3 得分 62.9%
- **Luna（月亮·快速）**：$1/$6，定位预算 agent 场景。KingBench 3 得分 44.3%，但作为"最便宜的 agent 模型"表现亮眼

OpenAI 同时发布了详细的系统卡，披露了安全评估、能力边界和限制策略。Sol 仍落后于 Fable 5 和 Opus 4.8 在前端/视觉任务上的表现，但在 agent 推理和数学上已大幅缩小差距。

📎 [OpenAI 官方](https://community.openai.com/t/introducing-gpt-5-6-series-sol-terra-and-luna-coming-july-9/1384931) | [explainx.ai 详解](https://explainx.ai/blog/gpt-5-6-sol-terra-luna-preview-june-2026) | [AICodeKing 实测](https://www.youtube.com/watch?v=xDXX2M5DrO0)

### 2. xAI 发布 Grok 4.5 — 1.5 万亿参数 MoE，Musk 称"Opus-class"

xAI 此前于 7月8日宣布、7月9日正式上线 **Grok 4.5**。基于 V9 基础架构打造，约 **1.5 万亿参数 MoE**（介于 Grok 4.3 和仍在训练的 Grok 5 之间的中间旗舰）。

可用渠道：SuperGrok Heavy / X Premium+ / xAI API。Elon Musk 称其为 "Opus-class"，beta 阶段已在 SpaceX 和 Tesla 内部团队中跑通。xAI 同时在 Colossus 2 上训练 7 个模型，含一个 10 万亿参数变体，Grok 5 API 预计 Q3 2026。

### 3. Mistral 进军机器人领域 — Robostral Navigate (8B)，单摄像头+自然语言导航

Mistral 于 7月7日发布、7月持续发酵的 **Robostral Navigate** 是公司首个面向具身导航（embodied navigation）的 AI 模型。仅 **8B 参数**，使用一颗普通 RGB 摄像头（无深度传感器），在 R2R-CE（连续环境中的房间到房间导航）验证集 unseen 上达到 **76.6%**，超越使用多传感器的方案。

这意味着：**紧凑型模型 + 单摄像头 = 足以实现 SOTA 的具身导航**。Mistral 全部在内部通过仿真训练 + token 高效技术完成，泛化到各种机器人形态。

📎 [Mistral AI 官方](https://mistral.ai/news/robostral-navigate) | [PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/mistral-introduces-robotics-ai-requires-only-one-camera)

### 4. DeepSeek DSpark 推测解码持续热议 — V4-Flash 加速 60-85%

6月27日开源的 **DSpark** 在 7月9日仍有大量讨论。核心数据：V4-Flash 加速 60-85%、V4-Pro 加速 57-78%，**无损失出质量**。

配套的 **DeepSpec** 工具包（MIT 协议开源）让任何团队都能为自己的模型训练 draft model。这是本月最重要的推理优化发布之一——它直接攻击实际运营中最大的成本：每条回复占用的 GPU 秒数。

📎 [buildthisnow.com](https://www.buildthisnow.com/blog/models/deepseek-dspark-speculative-decoding) | [arXiv 论文](http://arxiv.org/abs/2607.05147v1) | [Analytics Vidhya](https://www.analyticsvidhya.com/blog/2026/07/deepseek-dspark-speculative-decoding)

### 5. Karpathy 的 CLAUDE.md 突破 220K GitHub Stars — 4 条规则，65%→94%

Andrej Karpathy 的 **CLAUDE.md** 规则集在 GitHub 上已达到 **220,000 stars**。最初的 4 条规则将编码准确率从 65% 提升至 94%：

1. 模型会基于错误假设代你决策，不会回头检查
2. 需要明确告诉模型它"不知道"
3. 用示例（通过/失败）而非指令
4. 让模型分步思考，每一步自我验证

社区在此基础上扩展到 21 条规则体系。这已成为 AI 编码时代的 `.gitignore`——每个开发者都在抄这份配置。

### 6. Anthropic Sonnet 5 — 被称为"agent 利器"

Claude Sonnet 5 持续被社区称为当前**最具性价比的 agent 模型**。关键数据：

- SWE-bench Pro: **63.2%**
- Terminal-Bench 2.1: **80.4%**（+13.4 对比 Sonnet 4.6）
- 知识工作 Elo: **1618**（超越 Opus 4.8 的 1395）
- 支持 **1M context**
- 促销价 $2/$10（到 8月31日），之后 $3/$15

社区共识：Sonnet 5 在 agent 工作流上的 cost-performance 比正在重新定义"什么算可投产的 agent"。

### 7. UN 警告：AI 治理窗口不会长期保持开放

联合国独立国际人工智能科学小组（II-SPAI）发布初步报告，40 名全球专家共同撰写。核心判断：

> "AI 越是在没有共享规则的情况下前进，政府和人民能施加的影响就越小。"

联合国秘书长 António Guterres 在 7月1日记者会上明确表态。7月2日开始的 **全球 AI 治理对话**（Global Dialogue on AI Governance）在日内瓦持续进行。报告指出：AI 可能加剧全球不平等，而治理窗口正在关闭。

## 💡 技术洞见

- **历史性的一天**：GPT-5.6、Grok 4.5、Sonnet 5 三款顶尖模型同一天在市场上正面竞争。7月9日将被标记为 AI 史上模型最密集发布的日期之一。三家的差异化定位清晰：OpenAI 走三档全价格带覆盖，xAI 押注开源社区+X 生态，Anthropic 在 agent cost-performance 上卷性价比。

- **Mistral 的「单摄像头路线」** 值得深思——当业界认为机器人导航需要激光雷达+多目+IMU 时，Mistral 用 8B 参数+单 RGB 实现了超越。这呼应了 DrJimFan 在 MACHINA 2026 上的判断：2026 是"scaling robot learning without robots"之年，仿真训练+紧凑模型可能是正确的方向。

- **Karpathy 的 4 条规则** 之所以爆火，是因为它解答了 agent 落地中最痛苦的「模型会自作主张」问题。220K 星不只是对代码的关注，更是社区对「如何与 AI 正确协作」的方法论饥渴。

- **模型竞争的维度正在彻底改变**：从「谁的 benchmark 更高」→「谁能让 agent 工作流在合理成本下完成」。Sonnet 5 的 Terminal-Bench 80.4%、Sol 的 ExploitBench 效率、DSpark 的推理加速，都在指向同个方向——**能跑起来的 AI 才是好 AI**。
