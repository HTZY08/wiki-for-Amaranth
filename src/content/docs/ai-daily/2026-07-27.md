### 1. Kimi K3 开源权重今日（7/27）正式发布

@Kimi_Moonshot 官宣 Kimi K3：**2.8T 参数、百万上下文、原生多模态**。三项关键技术：
- **Kimi Delta Attention**：百万 token 上下文中解码速度提升最高 6.3 倍
- **Attention Residuals**：~25% 训练效率提升，额外成本 <2%
- 专为长 horizon agentic coding 和自演进工作流设计

@togethercompute 同日宣布在 Together AI 上线 K3。@piotrsankowski 实测称 K3 在编程和 agentic benchmark 上"与 Fable 5 和 GPT-5.6 Sol 相当"。@deanwball 独立验证认为 K3 表现不能简单归因于蒸馏，token 消耗量大但编码能力确为前沿水平（57K ❤️ / 7.6K RT）。

## 💡 技术洞见

### Karpathy 在 Sequoia Ascent 2026：LLM 打开了三个新维度

@karpathy 在 Sequoia AI Ascent 2026 炉边对话中提出核心观点：**LLM 的意义远超加速已有事物（如 coding）**。三个新 horizon：

1. **menugen** — 完全被 LLM 吞噬的应用，输入图像→输出图像，LLM 原生完成全流程，零经典代码
2. **install .md skills 代替 install .sh** — 为什么不把技能写成 markdown 而写成 bash 脚本？LLM 可以直接"安装 .md"
3. LLM 让传统软件 1.0 的很多中间层变得多余

6170 ❤️ / 812 RT，可能是近期最被低估的洞见之一。

→ https://x.com/karpathy/status/2049903821095354523

### DrJimFan 在 Sequoia 宣布 "RIP VLAs"：物理世界模型正在取代 VLA

@DrJimFan 的核心论点：**VLA（Vision Language Action Model）架构从根本上脆弱**——它们只是把机器人动作螺栓到 LLM 上。行业正在收敛到**物理基础的世界模型**。在机器人数据方面，**样本效率和数据结构正在取代暴力 token 量**。

@michellelsun 报道。
