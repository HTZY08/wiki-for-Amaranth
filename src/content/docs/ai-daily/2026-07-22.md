# AI云组会｜2026-07-22 星期三

## 🔥 今日热议

**1. GPT-5.6 Sol 正式上线：OpenAI 的"太阳"家族三箭齐发**

OpenAI 在 7 月 9 日低调预览后，本周 GPT-5.6 家族（Sol/Terra/Luna）全面铺开。Sol（旗舰）在 Agents' Last Exam 取得 53.6 分——领先 Claude Fable 5（自适应推理）13.1 分，Coding Agent Index 达 80 分超 Fable 5 2.8 分且成本低约 1/3。新增"ultra"多智能体模式（默认 4 agent 并行协作）。Luna 以约 1/16 成本匹敌 Fable 5。社区热议焦点是定名——"Sol"（拉丁语太阳）、"Terra"（大地）、"Luna"（月亮）取代了此前的数字+字母命名惯例。Elaina43114880 等用户报告称这是"更好的新 checkpoint"。

→ https://openai.com/index/gpt-5-6/

**2. Kimi K3 太火了——月之暗面被迫暂停新订阅**

Moonshot AI 的 2.8T 参数 1M 上下文开源模型 Kimi K3 上线后需求爆棚。官方账号 @Kimi_Moonshot 发帖（20883❤️）称 48 小时内需求逼近容量极限，为保护现有用户体验，临时暂停新订阅。已在加速扩容并分批开放新名额。Ethan Mollick 提醒社区不要过度依赖 Arena ELO 分数（264❤️）——"人们又在对一个 Arena 分数过度解读了（记得 Llama 4 吗？）ELO 分数受前端 UI 和 system prompt 影响大。"

→ https://x.com/Kimi_Moonshot/status/2078855608565207130
→ https://x.com/emollick/status/2077969350573572490

**3. xAI 双线作战：Grok for Excel + Grok Build v0.2.110**

xAI 本周动作密集。推出 **Grok for Excel**：用户用自然语言 prompt 直接建立财务模型、分析市场数据、生成图表。@v_shakthi 评价这是"把分析师变成 prompt 策略师"的关键工具。同时，Grok Build v0.2.110（7月21日）增加 MCP/插件/钩子源删除确认提示、会话创建失败可视化、过期 token 自动重试等改进。Grok Build v0.2.109（同日）新增 `/usage` 命令显示 token 用量和费用。工具链竞争白热化——@PawelHuryn 调侃"Claude Code 或 Codex 额度用完了？切换到 Grok Build 继续。"

→ https://x.com/blankspeaker/status/2079685099537461527
→ https://x.com/blankspeaker/status/2079615975465615397
→ https://x.com/v_shakthi/status/2079388883712868794

## 💡 技术洞见

**Patrick Moorhead：中国开源 AI 恐慌瞄准了错误目标**

@PatrickMoorhead 发表周前瞻（26❤️）认为 "cheap open models grow the inference market"——廉价开放模型实际在扩大推理市场，领先前沿仍需要大规模训练基础设施，而利润压力落在闭源模型 labs 上，而非超大规模云厂商。同贴提到 NVIDIA 在 SIGGRAPH 展示神经渲染、世界模型和仿真研究。

→ https://x.com/PatrickMoorhead/status/2078890956812620161

**Ethan Mollick：AI 其实很擅长想点子**

@emollick 发帖引发小规模讨论——"AI is actually pretty good at ideas as well." 结合他之前在 Kimi K3 话题上对基准分数的警示，体现其一贯立场：关注模型的实际创造力而不仅是榜单排位。

→ https://x.com/emollick/status/2026751796832776270

**Simon Willison：LLM 0.32a0 重大重构 + Datasette Agent**

Simon Willison 发布了 LLM 0.32a0——向后兼容的重大重构。同时 Datasette Agent 项目持续推进，用自然语言操作 SQLite 数据库，DSPy 评估改进 system prompt。sqlite-utils 4.0 也已发布。

→ https://x.com/simonw/status/2049567761136058699

**mvanhorn 让 Agent 读完 130 万行 Grok 开源代码**

@mvanhorn 发了一篇长文（183❤️）详述他让自己的 AI Agent 读取并理解 xAI 开源的 Grok 代码库全文（130 万行）。这既是工程实验也是极限压力测试，展示了当前 Agent 对超大代码库的覆盖能力。

→ https://x.com/mvanhorn/article/2077548703410540669
