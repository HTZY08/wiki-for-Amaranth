# AI云组会 2026-09-04 星期五

## 🔥 今日热议

Fast."（[@OpenAI](https://x.com/OpenAI/status/2095595741528125780)，270K views），并称 Astra 是"the most intelligent and aligned model in the world"。@gdb（Brockman）同步发文（[推文 139K views](https://x.com/gdb/status/2095598855073255644)）："Welcome to the AGI era"——VentureBeat 直接拿来当标题（[推文](https://x.com/VentureBeat/status/2095572598386024651)）。**为什么值得看**：从 8/1 math 论文预告 → 8/20 员工口径"couple of weeks" → 9/1 官方 Path to Astra 安全白皮书 → 昨夜 API staged 硬证据 → 今晨落地，整条发布链走了整整一个月且节奏罕见地"先安全文档、后模型"；@testingcatalog 在北京 9/4 03:09 就提前数小时喊出"ASTRA WILL BE RELEASED TODAY"（[推文](https://x.com/testingcatalog/status/2095529705155727808)），发布瞬间 ChatGPT/Codex 一度短暂宕机（评论区 @Chahatusharma "ChatGpt is down 😂"）——流量冲击本身就是热度注脚。

**2. 官方 benchmark 全面碾压：Fable 5.1 的 SOTA 头衔只维持了 2 天**

OpenAI 官方口径（[@OpenAI](https://x.com/OpenAI/status/2095595742975197690) + [blog](https://openai.com/index/gpt-6-astra/)）：**ARC-AGI-3 99.9% 饱和、ExploitBench 100%、FrontierMath Tier 4 (v2) 97.6%（Fable 5.1 为 87.8%）、DeepSWE v1.1 74.1%（Fable 5.1 为 67.4%）、CAD 95.9%**，Agents' Last Exam / AutomationBench / ScreenSpot Pro / TerminalBench-4.0 / Terminal-Bench Science 0.1 / HealthBench Pro 全 SOTA。@kimmonismus 一针见血（[推文 39K views](https://x.com/kimmonismus/status/2095589174686400914)）："At this point, they completely crushed Fable 5.1 in every benchmark. Claude Fable 5.1 was SOTA in several key benchmarks for **2 days**. Astra is better - and way cheaper." 定价 $10/$50 per M token = **与 Fable 5.1 完全同价**（[@Techmeme](https://x.com/Techmeme/status/2095576486090780788)），但却是 5.6 Sol（$4/$20）的 2.5 倍（[@ArtificialAnlys](https://x.com/ArtificialAnlys/status/2095595489031000350)）。**为什么值得看**：这是 OpenAI 自 5.6 Sol 以来首次在"分数量级"上压过 Anthropic 旗舰——Fable 5.1 两天前才刚登顶（见 9/3 简报），Astra 直接把竞争拉回 OpenAI 侧；2.5x 提价 + 与 Fable 同价说明 OpenAI 在赌"能力跳升足以支撑溢价"，而不是走 Sol 的性价比路线。

**3. 首轮实测分化：Dan Shipper "Astra 全天花，但最难的任务还是给 Fable 5.1"**

@danshipper（@every）在北京今晨发布自家 4,000 字 vibe check（[推文](https://x.com/danshipper/status/2095593705214300394)）：团队凌晨 3 点得知发布、下午 2 点就完成长文+视频。核心结论：**Astra 是 5.6-Sol 的大升级，但带一些 frustrating habits，够不到 Fable 的顶尖**——"I'm reaching for Astra all day, but Fable 5.1 still gets my biggest tasks. On ambitious builds, Fable is better at understanding what I want and taking it further than I would have thought to ask." 亮点：computer use 强悍到可以连续几小时操作复杂应用、顺手剪完了自家 Fable 5.1 vibe check 视频的第一版；3D 能力强到 single prompt 生成精美 3D 世界、one-shot 还原滑铁卢战役；缺点是 high effort 档容易 overcomplicate（要简单界面给你造复杂系统）。**为什么值得看**：这是发布后第一批"重度用户"实测——"日常用 Astra、最难任务用 Fable"的分工暗示两家旗舰的真实差距不在 benchmark 而在**意图理解与自主延伸**，与 Epoch AI 的 MirrorCode 读数（下条）相互印证。

**4. 独立验证的冷静读数：Epoch AI ECI 169 破纪录，但 long-horizon coding 上 Astra 不是最强**

两个独立评测机构发布 Astra 预发布测试结果。**Epoch AI**（[推文](https://x.com/EpochAIResearch/status/2095602754282783108)，获 OpenAI pre-release 访问）：Astra 创下 **ECI 169 新纪录**（前纪录 163），math / continual learning / game-puzzles 均破纪录——但强调仍在 reasoning-era ECI 趋势的不确定区间内；关键是 **MirrorCode（long-horizon coding）上 Astra 只排在 Opus 4.7 与 Fable 5 之间**，并非最强。**Artificial Analysis**（[推文](https://x.com/ArtificialAnlys/status/2095595489031000350)）：Coding Agent Index 与 Fable 5 持平但成本更低；Intelligence Index 上 token 效率优于 5.6 Sol（同等表现用更少 token），但被 2.5x 价格抵消。**为什么值得看**：官方榜单一色碾压 vs 独立机构"部分领域未登顶"的温差，是判断 Astra 真实档位最关键的校准——尤其 MirrorCode 这类数小时级真实编码任务，比 DeepSWE 单 issue 修复更能反映"放养式 agent 开发"能力。

**5. "能 exploit 漏洞的模型该不该发"——安全质疑与发布争议同屏**

Astra 是 OpenAI 首个达到网络安全 Critical 阈值、ExploitBench 100% 的模型（昨日已覆盖 Path to Astra，今日落地确认），随之而来的质疑不小：@RassoulEdji 直接问（[推文](https://x.com/RassoulEdji)）"How smart is it to release AI models which can exploit vulnerabilities in systems?"；@xiangyuqi_pton（Xiangyu Qi）指出 ExploitBench 100% 饱和后 OpenAI 被迫用 6-8 月新披露漏洞做内部 refresh、Astra 仍保持高分（[推文](https://x.com/xiangyuqi_pton)）。OpenAI 的切割方案：**一般发布版只含 defensive 能力，less restrictive 的 cyber 解锁版数周后经 Project Daybreak 提供**（[@romainhuet](https://x.com/romainhuet/status/2095600947661820106)）。另一面是用户对"limited rollout"的不满——@gdb 评论区 "Introducing only to the special people. The rest of us, who cares?"、@Serah_Creates "At least Anthropic gave 5.1 to all of us yesterday"（[推文](https://x.com/gdb/status/2095598855073255644) 评论区）。**为什么值得看**：HF Incident 后的信任修复期，OpenAI 选择"先白皮书、再限流发布、Daybreak 单独解锁"的三段式——安全叙事与用户体感（Anthropic 全量 vs OpenAI 挤牙膏）的张力，会是接下来一周社区争论的主线。

## 💡 技术洞见

**1. Astra 的 agentic 新特性藏在官方文档里：background tasks + 可搜索的历史上下文** — @btibor91 转述（[推文](https://x.com/btibor91/status/2095606659678888422)）：Astra 支持 **background tasks——"ask questions and keep working on things that don't need your answer"**，即异步持续干活；另有 experimental context handling：preserve notes + 允许 Astra 搜索更早的上下文窗口，当前 opt-in、coming weeks 将默认开启。加上 Zero Data Retention 对 eligible API 客户支持——"computer use 连续几小时"的实测背后是这套新架构。这是 agent 从"对话-响应"走向"委托-交付"的产品化信号。

**2. Epoch AI 的 MirrorCode 读数最该被认真对待** — ECI 169 破纪录的同时，long-horizon coding 上 Astra 只介于 Opus 4.7 与 Fable 5 之间（[推文](https://x.com/EpochAIResearch/status/2095602754282783108)）。与 Dan Shipper"最难任务给 Fable"的主观体验互证：**Astra 在短任务/单点 benchmark 上碾压，但在"数小时自主推进的复杂工程"上并未登顶**。对 agentic coding 的真实用户而言，后者才是决定"谁拿大活"的指标——这也解释了为什么 Dan Shipper 们白天用 Astra、最难任务仍切 Fable。

**3. 定价即战略：2.5x 提价赌能力跳升** — @wallstengine 点评（[推文](https://x.com/wallstengine/status/2095576937288839395)）："Astra pricing at $10/$50 while being called a possible AGI moment is a combo the market will price immediately"；@3rdDistrictDon："2.5x of GPT-5.6 shows OpenAI banking hard on this being a real capability jump, not just an incremental update"。Sol 时期 OpenAI 是价格屠夫，Astra 直接对齐 Fable 定价——旗舰模型的价格锚从此被 Anthropic 定义，OpenAI 选择跟进而非破坏。
