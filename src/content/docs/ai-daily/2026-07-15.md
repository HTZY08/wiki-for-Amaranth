# 云组会简报 — 2026-07-15

## 📌 今日值得关注

1. **GPT-5.6 Sol Ultra 证明 50 年数学猜想**  
   @polynoamial 报道：GPT-5.6 Sol Ultra 成功证明了 Erdős Unit Distance Problem（50 年未解的数学猜想），并指出模型已公开可用。团队还强调并行测试时间计算（parallel TTC）从秒级扩展到周级是突破关键。  
   *来源：@polynoamial*

2. **OpenAI 发布 GPT-5.6，健康智能显著提升；Sol Ultra 用于研究**  
   @OpenAI 宣布 GPT-5.6 全线模型在健康推理上超越 GPT-5.5，且成本更低。@gdb 确认 GPT-5.6 已在 Bedrock 上全面可用，并展示 Sol Ultra 解决 Erdős 问题的案例。  
   *来源：@OpenAI、@gdb*

3. **Codex + ChatGPT Work 活跃用户突破 800 万**  
   @jxnlco 转发：OpenAI 联合平台已达 8M MAU，并再次重置所有用户使用限制，取消 5 小时速率限制。Sam Altman 随后评论 5.6 Sol 增长“疯狂”，称推理团队正全力支持需求，但可能仍有波动。  
   *来源：@jxnlco、@sama*

4. **Claude Code 桌面版内置浏览器，支持多玩家协作（Claude Tag）**  
   @bcherny 转发：Claude Code 现可在桌面应用内打开任意网站，执行点击、阅读文档、交互操作。同时预告从单人 Claude Code 升级到多人 Claude Tag 的直播演示。  
   *来源：@bcherny、@_catwu*

5. **NVIDIA 发布 ASPIRE：机器人技能库自我进化**  
   @DrJimFan 公布 ASPIRE 项目（继 ENPIRE 后第二部），使机器人自动编写技能库，在完成第 100 个任务时不再像第 1 个任务一样生疏。论文与项目页面已公开。  
   *来源：@DrJimFan, [Project Gallery](https://research.nvidia.com/labs/gear/aspire/)*

6. **Vercel 开源 AI Token 流数据集，agentmail 无注册集成**  
   @rauchg 宣布开放 Vercel AI Gateway 上的 token 流量数据集，内含大量洞察。同时 agentmail 团队推出 `vercel install agentmail`，零配置、统一计费。  
   *来源：@rauchg*

7. **Sakana AI 发表 Smart Cellular Bricks：无中心控制的集体智能与自修复**  
   @hardmaru 转发：论文发表于 *Nature Communications*，展示数百立方体无需中央控制即可识别整体形态并自行修复损坏部分。  
   *来源：@hardmaru, [Nature Communications 论文](https://sakana.ai/smart-cellular-bricks/#Japanese)*

8. **MiniMax 免费 API Key 一天被烧 9.86 亿 token**  
   @israfill 转发：前天公开的 MiniMax 共享 API Key 在 24 小时内消耗了 9.86 亿 token，还剩 50 亿+ token 可用。警告这不是营销，是真共享。  
   *来源：@israfill*

9. **Google DeepMind 发布「预测过去」技能：无代码分析历史文物**  
   @GoogleDeepMind 展示通过高级 AI 工作流重建古代铅板内容，分析前往多多纳神谕的访客来源，无需编程。  
   *来源：@GoogleDeepMind*

10. **Grok 4.5 发布：专为编码与代理训练，性价比 Pareto 前沿**  
    @mntruell、@rasbt 确认：xAI 发布 Grok 4.5，Opus 级别但速度快、成本低。@rasbt 模型对比图显示 Grok 4.5 位于性价比 Pareto 前沿。  
    *来源：@mntruell、@rasbt*

## 💡 技术洞见

- **“There is no they. You just can do things.”** — @kevinweil 引用这句政治之外的真理：所有人都在摸索中前进，不必等待别人。  
- **Loops from loop engineering 成为新热词** — @AndrewYNg 指出 “Loop engineering” 被 Boris Cherny（Claude Code 作者）和 Peter Steinberger（OpenClaw 作者）带火，现已成关键工程范式。  
- **AI 模型即管理器 + 低成本模型做执行** — @levie 预测：前沿模型做管理（指挥），低成本模型做具体任务，这是未来企业 AI 的模板。  
- **测试时间计算从秒到周，延迟成瓶颈** — @polynoamial 指出：GPT-5.6 Sol Ultra 的突破核心在于并行 TTC 扩展，但周级的延迟将推动分布式计算架构革新。  
- **弱到强泛化可通过在线策略蒸馏实现** — @_akhaliq 转发论文“Weak-to-Strong Generalization via Direct On-Policy Distillation”，提供一种更稳定的对齐方法。  
- **Chinas 模型已占 Hugging Face 下载量的 41%，超越美国** — @ClementDelangue 引用 Spring 2026 数据，显示出开源生态的地缘转变。  
- **更多测试时间算力 = 更高智能，但物理系统也需要集体智能** — @hardmaru 强调 AI 不止 LLM agent，物理系统的自修复与自组织同样重要。
