## 🔥 今日热议

### 1. GPT-5.6 Sol Ultra 证明 50 年未解数学猜想——但跟你听说的不一样

@polynoamial（Noam Brown）7/10 公布：GPT-5.6 Sol Ultra 用 64 个并行子代理，在不到一小时内生成了 **Cycle Double Cover Conjecture** 的完整证明——一个悬而未决 50 年的图论猜想。这是首个**公开可用模型**产出此类原创数学成果的案例。

> ❗预采集脚本误写为"Erdős Unit Distance Problem"。真实情况：此前 GPT-5.5 曾涉足 Erdős 问题，但 Sol Ultra 解决的是不同的 Cycle Double Cover Conjecture。

@polynoamial 特别强调："Unlike the Erdős Unit Distance Problem, this was done with a model publicly available *today*。"团队公开了完整 prompt 和证明供独立验证，数学界正在评审中。

@gdb（Greg Brockman）7/13 补充：Sol Ultra 也在解决 Erdős 问题 #793（2-primitive 集渐近性质），且构建了极短优雅的解。

- 来源：[@polynoamial](https://x.com/polynoamial/status/2075646048425431469) ❤️3433 | [@gdb](https://x.com/gdb/status/2076799732736041284) ❤️759
- 意义：证明从"AI 解已知问题"到"AI 创造新知识"的转折点。并行 TTC 从秒级到小时级是关键突破。

### 3. Grok 4.5 发布：编码/Agent 特化，性价比 Pareto 前沿

xAI 7/8 发布 Grok 4.5——**首个专为编码和 agent 场景训练的模型**，基于 V9 MoE 架构，额外融入数万亿 tokens 补充训练。与 Cursor 联合训练优化。

@rasbt 的模型对比图显示 Grok 4.5 位于**性价比 Pareto 前沿**——Opus 级能力，更快的速度和更低的成本。@sudoingX 实测展示：grok 4.5 一次 prompt 冷启动构建完整 3D 场景，所有测试全绿。

⚠️ 欧盟暂不可用，预计 7 月下旬起逐步推出。

- 来源：[@rasbt](https://x.com/rasbt) | [@sudoingX](https://x.com/sudoingX/status/2076367883664499000)

### 4. NVIDIA ASPIRE：机器人技能库的自我进化

@DrJimFan（Jim Fan）首次公开 ASPIRE 项目——作为 ENPIRE 的后续，它赋予机器人一个**自动编写和精化控制程序的能力库**。

核心机制：每完成一个任务，失败修复会蒸馏为可复用的文本技能（failure signature + when-to-apply guard + repair sketch），第 100 个任务的机器人比第 1 个聪明得多。
- LIBERO-Pro Long 零样本：31% vs 此前方法的 4%
- Robosuite 双手交接：92 vs 20
- 论文与项目页面已公开

- 来源：[@DrJimFan](https://x.com/DrJimFan) | [Project Gallery](https://research.nvidia.com/labs/gear/aspire/)
- 意义：代码即策略（code-as-policy）vs 主流 VLA/World Model 路线的差异化竞争
