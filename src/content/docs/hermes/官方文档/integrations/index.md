# 集成总览

Hermes Agent 通过丰富的集成能力与外部系统对接，涵盖 AI 推理、工具服务器、IDE 工作流、编程接口等场景，全面拓展 Hermes 的能力边界。

## AI 提供商与路由

通过内置的提供商支持，将 Hermes 连接到前沿及本地 LLM——支持 OpenRouter、Nous Portal、Anthropic、OpenAI、GitHub Copilot、Google Gemini、DeepSeek 以及自定义/自托管端点。

## 工具网关

Nous Portal 工具网关提供网页搜索、图像生成、语音合成（TTS）和浏览器自动化——无需额外 API 密钥。

## 辅助模型

了解如何将特定任务（视觉理解、摘要生成、上下文压缩）路由到更便宜、更快的模型，同时保持主对话体验由前沿模型驱动。

## 消息平台

将 Hermes 连接到 Telegram、Discord、Slack、WhatsApp、Teams 等消息平台。

## 编程接口

通过 Python 库的形式在自有代码中使用 Hermes，或通过 REST API 进行程序化调用。

## IDE 集成

通过 Claude Code、Codex CLI 或 ACP 协议将 Hermes 接入你的编辑器。

## 外部工具

Hermes 集成网页搜索、浏览器自动化、图像生成、语音合成（TTS）、代码执行和文件操作等多种外部工具。
