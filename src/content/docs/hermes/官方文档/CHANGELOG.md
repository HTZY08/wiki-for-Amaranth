# 官方文档汉化同步记录

本文档记录 Hermes Agent 官方文档更新后，Orchid 执行汉化同步的时间线和变更详情。

## 格式

每次同步记录包含：
- **时间**：执行同步的日期
- **来源**：官方文档版本（基于 [llms-full.txt](https://hermes-agent.nousresearch.com/docs/llms-full.txt) hash）
- **变更类型**：新增、更新、移除
- **涉及页面**：变更的具体页面路径
- **操作**：Orchid 执行的操作

---

### 2026-06-30 — 初始化同步基线

- **操作**：建立首次汉化基线
  - 基于官方文档全量快照，建立 Hash 缓存
  - 汉化 97 个核心页面已完成
  - 记录官方文档 98 个页面索引
- **注意**：初始基线，后续更新将对差异做标记

## 同步流程说明

1. 定期巡检（cron job）自动检查官方 llms-full.txt hash
2. 检测到变更后对比页面级 hash
3. 生成差异报告投递到飞书
4. Orchid 根据报告执行汉化更新
5. 更新完成后在本文档追加记录
