# 并购模型

构建并购交易的增厚/稀释分析。模拟模拟每股收益影响、协同效应敏感性和购买价格分配。在评估潜在收购、准备演示用的并购后果分析或就交易条款提供建议时使用。

## 工作流程

### 第一步：收集输入

**收购方：**
- 公司名称、当前股价、流通股数
- 过去十二个月（LTM）及未来十二个月（NTM）每股收益（GAAP 和调整后）
- 市盈率（P/E）
- 税前债务成本、税率
- 资产负债表上的现金、现有债务

**目标公司：**
- 公司名称、当前股价、流通股数（若为上市公司）
- 过去十二个月（LTM）及未来十二个月（NTM）每股收益或净利润
- 企业价值（Enterprise Value）或股权价值

**交易条款：**
- 每股要约价格（或相对当前价格的溢价）
- 对价构成：现金占比 vs 股票占比
- 为支付现金部分新筹集的债务
- 预期协同效应（收入和成本）及逐步实现时间表
- 交易费用和融资成本
- 预期完成日期

## 重要说明

- 始终在相关处同时显示 GAAP 和调整后（现金）每股收益
- 股票交易：使用收购方当前股价计算换股比例，注意新股带来的稀释
- 包含购买价格分配 — 商誉和无形资产摊销对 GAAP 每股收益有影响
- 协同效应的逐步实现至关重要 — 第1年通常仅为常态化协同效应的25-50%
- 不要忽略因使用现金而损失的利息收入以及因新增债务产生的利息支出
- 协同效应和利息调整的税率应与收购方的边际税率一致

## 数据来源 — 优先使用 MCP，其次使用网络搜索

下文许多地方提到“使用 S&P Kensho MCP / Daloopa MCP / FactSet MCP”。这些是原 Cowork 插件环境中的商业金融数据 MCP。在 Hermes 中：

- **如果你配置了任何结构化的金融数据 MCP**（Hermes 支持 MCP — 参见 `native-mcp` 技能），则优先用于获取即期可比公司、先例交易和监管文件。
- **否则**，回退到：
  - `web_search` / `web_extract` 查询美国证券交易委员会的 EDGAR 系统（`https://www.sec.gov/cgi-bin/browse-edgar`）获取美国公司文件
  - 公司投资者关系页面获取新闻稿、财报演示材料
  - `browser_navigate` 访问交互式数据门户
  - 用户提供的数据（当上下文缺少数据时明确询问）
- **切勿编造数据**。如果无法获取某个倍数、先例或文件编号，将该单元格标记为 `[UNSOURCED]` 并告知用户。
