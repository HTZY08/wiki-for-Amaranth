## 输出检查清单

在交付可比分析之前，请核实：
- [ ] 所有公司确实具有可比性
- [ ] 数据来自一致的时间段
- [ ] 单位清晰标注（百万/十亿）
- [ ] 公式引用单元格，而非硬编码值
- [ ] **所有硬编码输入单元格都带有注释，其中包含：(1) 引用确切数据来源的引文，或者 (2) 带有解释的明确假设**
- [ ] **在相关处添加超链接**（SEC EDGAR 备案、彭博页面、研究报告）
- [ ] 统计指标至少包含 5 个分位数（最大值、第75百分位、中位数、第25百分位、最小值）
- [ ] 注释部分记录了来源和方法论
- [ ] 视觉格式遵循惯例（蓝色 = 输入，黑色 = 公式）
- [ ] 合理性检查通过（利润率合理，倍数合理）
- [ ] 日期戳是当前的（“截至 [日期]”）
- [ ] 公式审计显示无错误（#DIV/0!、#REF!、#N/A）

## 持续改进

完成可比分析后，请思考：
1. 统计数据是否揭示了意想不到的见解？
2. 是否存在限制分析的数据缺口？
3. 利益相关者是否要求了您未包含的指标？
4. 实际花费的时间与理想花费的时间相比如何？
5. 下次如何让分析更有用？

最佳的可比分析随着每次迭代而演进。保存模板，从反馈中学习，并根据决策者的实际使用情况优化结构。

## 数据来源 — 优先使用 MCP，后备使用网络

下文许多段落提到“使用 S&P Kensho MCP / Daloopa MCP / FactSet MCP”。这些是来自原始 Cowork 插件环境的商业金融数据 MCP。在 Hermes 中：

- **如果您配置了任何结构化金融数据 MCP**（Hermes 支持 MCP — 参见 `native-mcp` 技能），则优先将其用于时点可比分析、先例交易和备案文件。
- **否则**，回退到：
  - 对 SEC EDGAR (`https://www.sec.gov/cgi-bin/browse-edgar`) 使用 `web_search` / `web_extract` 获取美国备案文件
  - 公司投资者关系页面获取新闻稿、财报演示
  - `browser_navigate` 访问交互式数据门户
  - 用户提供的数据（当上下文中没有时，明确询问）
- **切勿虚构**。如果某个倍数、先例或备案编号无法找到来源，请将单元格标记为 `[UNSOURCED]` 并向用户显示。
