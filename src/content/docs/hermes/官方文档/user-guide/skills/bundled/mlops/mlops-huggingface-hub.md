## 高级用法与技巧

### 全局标志（Global Flags）
*   `--format json`：生成机器可读的输出，便于自动化。
*   `-q` / `--quiet`：仅输出 ID 以限制输出。

### 扩展（Extensions）与技能（Skills）
*   **扩展（Extensions）：** 通过 GitHub 仓库使用 `hf extensions install REPO_ID` 扩展 CLI 功能。
*   **技能（Skills）：** 使用 `hf skills add` 管理 AI 助手技能。
