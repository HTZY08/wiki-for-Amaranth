## Hermes Agent 是什么

Hermes Agent 是一个**自托管的 AI 代理系统**。简单说就是：一个能替你执行任务的 AI 程序，跑在你自己的电脑上。

### 它能做什么

- **日常对话** — 像 ChatGPT 一样的问答
- **操作电脑** — 执行命令、读写文件、运行脚本
- **搜索信息** — 联网查资料、看网页内容
- **定时任务** — 每天早上给你推送新闻摘要
- **手机交互** — 通过微信/Telegram 与 AI 聊天
- **语音处理** — 语音转文字、文字转语音
- **图片识别** — 理解图片内容

### 和网页版 AI 有什么区别

| | 网页版 ChatGPT | Hermes Agent |
|---|---|---|
| 运行位置 | 云端服务器 | **你的本地电脑** |
| 能否操作本地文件 | ❌ 不可以 | ✅ 能读写你的文件 |
| 能否定时执行 | ❌ 不可以 | ✅ 支持定时任务 |
| 能否调用本地工具 | ❌ 不可以 | ✅ 能运行命令、脚本 |
| 隐私性 | 数据上传到云端 | 数据在本地处理 |
| 费用 | 按月订阅 | 按 API 调用量付费 |

## 系统架构

Hermes 是一个**多模型代理系统**，不依赖单一 AI 模型：

```
你的输入（微信 / 命令行 / 定时触发）
    │
    ▼
Hermes Agent（核心程序）
    │
    ├── 分析任务类型 → 选择合适的 AI 模型
    ├── 调用工具（查网页、执行命令、读写文件...）
    ├── 汇总结果
    │
    ▼
输出返回给你
```

## 关键概念

### Agent（代理）
核心程序，接收你的指令，决定调用什么工具和模型来完成任务。

### Model（模型）
背后调用的 AI 大语言模型，如 DeepSeek、GPT、Claude 等。不同模型专长不同：有的快、有的擅长编程、有的善于深度分析。

### Skill（技能包）
预定义的"操作说明书"，告诉 Agent 如何完成特定任务。比如"怎么查 arXiv 论文"、"怎么写 PPT"。

### Gateway（网关）
消息接入层，把微信、Telegram 等平台的消息转给 Hermes。相当于 Agent 的"通信接口"。

### Cron（定时任务）
设定时间自动触发任务，比如每天早上 9 点生成新闻摘要。

## 开始之前需要准备

- 一台能联网的电脑（Windows / Linux / macOS）
- 基本的命令行操作能力
- 一个 AI API 服务的订阅（如 DeepSeek、OpenAI）
