---

## 基础检查

### 容器状态

```bash
docker compose ps
```

应该看到两个容器状态都是 `Up`（运行中）：

```
NAME                STATUS          PORTS
hermes-agent        Up              ...
mihomo              Up              ...
```

### CLI 交互

```bash
docker exec -it hermes-agent hermes
```

看到欢迎信息和命令提示符，说明程序正常。输入一些测试指令：

```
你：你好
Hermes：你好！有什么可以帮你的？

你：现在几点了？
Hermes：需要先获取当前时间...
（应该返回正确的日期时间）
```

### 联网能力

```
你：帮我查一下今天的天气
```

应该能联网搜索并返回天气信息。如果报错提示网络问题，检查[代理配置](/hermes/proxy-setup/)。

| 功能 | 测试方法 | 预期结果 |
|------|---------|---------|
| 基础对话 | `你好` | AI 正常回复 |

## 进阶测试

### 多轮对话

连续问几个相关的问题，确认 Agent 能记住上下文：

```
你：我叫小明
你：我叫什么名字？
```

应该记得你叫小明。

### 工具调用

```
你：给我生成一个 6 位随机密码，保存到 password.txt
```

Agent 应该执行 Python 代码生成密码并写入文件。

## 常见问题

### 命令执行后无输出

```bash
# 查看日志找错误
docker compose logs hermes
```

### 响应特别慢

```bash
# 检查模型路由配置——是否用了最快的模型
# DeepSeek 通常响应最快
```

### 功能正常但部分工具不能用

某些工具需要额外安装。具体问题具体排查，参考对应的功能手册。

### 图片生成（AI 绘图）用不了

**原因**：默认部署的容器没有 GPU 访问权限。

**解决（二选一）**：

- **有独立显卡** → 配置 GPU 透传，参见 [Docker 部署 → 高级配置：GPU 透传](/hermes/docker-deploy/#高级配置gpu-透传)
- **没有显卡 / 不想折腾** → 配置云端 API 生图，无需 GPU，参见 [云端生图配置](/hermes/cloud-image-gen/)
