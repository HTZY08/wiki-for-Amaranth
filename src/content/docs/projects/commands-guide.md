> 斜杠命令是 Hermes 的快捷操作——以 `/` 开头，在对话中输入。

---

## 基础命令

### `/new`

开始一个新对话。当前对话的历史会被清空。

```bash
# 什么时候用：
# - 话题已经完全变了
# - AI 越来越偏，不如重新开始
# - 当前上下文太长了
```

### `/stop`

中断正在执行的 AI 回复。AI 会停下手头的事等你下一条消息。

```bash
# 什么时候用：
# - AI 在跑一个很长的任务但你想打断
# - AI 的方向错了
# - 你改主意了
```

## 任务控制

### `/background`（高频使用）

将当前任务转入后台独立执行。转后台后 AI 会释放前台，你可以继续发别的消息。任务完成后自动通知。

```bash
# 什么时候用：
# - 一个耗时任务（如"处理这100张图"）
# - 训练/批量处理/全量扫描
# - 构建/部署
# - 爬取大量数据

# 示例：
# 你："把整个代码库扫描一遍找出所有TODO"
# AI 会识别为长任务 → 自动转后台
# 你可以在后台跑的时候继续聊别的
# 跑完了收到通知
```

自动判断规则：

| 触发后台化 | 不触发后台化 |
|-----------|-------------|
| 用户说"后台跑/慢慢做/跑完告诉我" | 用户问概念（"什么是X"） |
| 批量处理、训练、全量扫描 | 要求只写不执行（"给我命令"） |
| 构建部署、爬取、监控轮询 | 要求同步完成（"现在做"） |
| 工具调用链天然漫长 | 单步轻量操作 |

> **误判了怎么办？** 回复"不用后台，现在做"即可切回前台。

## 会话管理

### `/echo`

让 AI 复述你说的话。用于测试连接是否正常。

### 对话中直接输入

```bash
# 不是命令，但常用：
# "继续" — 让 AI 继续上次没说完的内容
# "说不知道" — 不确定时直说，别编
```

## 平台相关

### WeChat 特定

```bash
# 语音消息 → 自动转文字后回复
```

### `/insights`

查看当前系统的用量统计和模型调用情况。只在 Hermes TUI 中可用。

### `/usage`

同 `/insights`，查看用量详情。
