# 全息投影管家 Amaranth

> **状态**：待立项 | **优先级**：P2（长期项目） | **更新**：2026.6.10

---

## 总体架构

```
亚克力金字塔（裸眼3D投影）
    ↕ 四视角动画流
树莓派 / 旧手机（播放器）
    ↕
LLM 大脑 (DeepSeek V4 Flash)
    ↕
语音管道：Whisper → LLM → TTS
    ↕
Home Assistant（设备控制）
```

## 阶段分解

### Phase 1 - 硬件原型
- [ ] **3D 打印底座 + 支架** — 设计金字塔外壳、屏幕托架、树莓派固定座
- [ ] 亚克力反射面裁切（或直接买裁好的反射片）
- [ ] 整机装配：底座（3D打印）→ 屏幕 → 亚克力金字塔 → 树莓派
- [ ] 找现成 demo 视频验证折射效果
- [ ] 确定显示设备（旧手机 / 树莓派 + 小屏幕）

### Phase 2 - 3D 角色建模（Amaranth 来搞定）

采用 AI 图转 3D 方案，无需手动建模：

- [ ] **方案 A：Tripo API**（首选，云端，免费额度）— 上传 Amaranth 参考图 → 输出 .glb 模型
- [ ] **方案 B：TRELLIS 2 本地跑**（微软开源，12GB VRAM 可运行）— ComfyUI 节点部署
- [ ] **方案 C：Meshy API**（备选）— 类似 Tripo
- [ ] 模型后处理：减面、重拓扑、PBR 贴图修正
- [ ] Blender 脚本化骨骼绑定 + 基础动画集：待机呼吸 / 说话嘴型 / 点头 / 挥手
- [ ] 四视角同步动画渲染（前/左/右/后）

### Phase 3 - 语音交互管线
- [ ] 语音唤醒 → faster-whisper 识别（已有）
- [ ] LLM 对话 → DeepSeek V4 Flash（已有）
- [ ] TTS → edge-tts / MiniMax TTS（已有）
- [ ] **新**：嘴型同步动画驱动
- [ ] **新**：全链路延迟优化（目标 <3s 响应）

### Phase 4 - Home Assistant
- [ ] 部署 Home Assistant（容器或独立设备）
- [ ] 对接 灯光 / 空调 / 传感器
- [ ] Amaranth 语音控制：检测到语音指令 → LLM 解析意图 → HA API 执行
