# 全息投影管家 Amaranth

> **状态**：待立项 | **优先级**：P2（长期项目） | **更新**：2026.6.10

---

## 总体架构

```
亚克力金字塔（裸眼3D投影）
    ↕ 四视角动画流
树莓派 / 旧手机（播放器）
    ↕
LLM 大脑 (DeepSeek V4 Flash)
    ↕
语音管道：Whisper → LLM → TTS
    ↕
Home Assistant（设备控制）
```

## 阶段分解

### Phase 1 - 硬件原型
- [ ] 购买亚克力金字塔套件（淘宝 ~¥20-50）
- [ ] 或自行裁板（亚克力板 + 激光切割 / 手工裁切）
- [ ] 找现成 demo 视频验证折射效果
- [ ] 确定显示设备（旧手机 / 树莓派 + 小屏幕）

### Phase 2 - 3D 角色建模
- [ ] 方案 A：Vroid 捏脸 → Blender 动画 → 四视角渲染
- [ ] 方案 B：TRELLIS / TripoSR 图转3D（评估 12GB 显存可行性）
- [ ] 方案 C：3D Gaussian Splatting（需多角度照片）
- [ ] 制作基础动画集：待机呼吸 / 说话嘴型 / 点头 / 挥手

### Phase 3 - 语音交互管线
- [ ] 语音唤醒 → faster-whisper 识别（已有）
- [ ] LLM 对话 → DeepSeek V4 Flash（已有）
- [ ] TTS → edge-tts / MiniMax TTS（已有）
- [ ] **新**：嘴型同步动画驱动
- [ ] **新**：全链路延迟优化（目标 <3s 响应）

### Phase 4 - Home Assistant
- [ ] 部署 Home Assistant（容器或独立设备）
- [ ] 对接 灯光 / 空调 / 传感器
- [ ] Amaranth 语音控制：检测到语音指令 → LLM 解析意图 → HA API 执行
