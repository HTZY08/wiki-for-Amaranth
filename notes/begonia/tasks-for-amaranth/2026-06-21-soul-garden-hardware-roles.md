# Soul Garden · 智能家居硬件分工

## 核心原则

无论树莓派还是NUC，都不跑本地大模型。所有推理走云端API（跟现在一样），本地硬件只做：**设备控制 + 数据采集 + 实时响应**。

```
传感器 → 树莓派/NUC → 决策（云端API）→ 树莓派/NUC → 设备执行
         本地           推理走网络             本地
```

---

## 树莓派5 (8G) — 分散式节点

### 定位：轻量节点，每个房间一个

树莓派不试图做所有事，而是**一个房间/一个功能区放一个**。

### 每个树莓派负责

| 功能 | 说明 |
|:--|:--|
| Zigbee网关（CC2531/CC2652P USB直插） | 连本房间的传感器和开关 |
| 本地传感器直读 | GPIO接DHT22温湿度、PIR人体感应、BH1750光照 |
| 红外发射（GPIO+IR LED） | 控制本房间的空调/电视/机顶盒 |
| 音频输入（USB麦克风） | 本地语音采集，传云端识别 |
| 音频输出（3.5mm/HDMI） | TTS播报、音乐播放 |
| 摄像头（USB摄像头） | 本地画面采集，传云端分析 |
| MQTT客户端 | 跟主控节点通信 |

### 部署方式

```
         ┌──── NUC（主控）────┐
         │  HomeAssistant      │
         │  MQTT Broker        │
         │  调度M（万寿菊）     │
         └──────┬─────────────┘
                │ MQTT/WiFi
    ┌───────────┼───────────┐
    │           │           │
 ┌──┴──┐   ┌───┴───┐   ┌──┴──┐
 │ 树莓派 │   │ 树莓派 │   │ 树莓派 │
 │ 客厅  │   │ 卧室   │   │ 厨房  │
 │Zigbee  │   │Zigbee  │   │Zigbee  │
 │红外   │   │传感器  │   │烟雾   │
 └───────┘   └───────┘   └──────┘
```

### 成本

单台树莓派5 (8G) + 外壳 + 电源 + SD卡 ≈ ¥600
每加一个房间 ≈ ¥600 + 传感器 ¥100-200

**适合场景：** 两室一厅或更大，每个房间独立控制

## NUC (16G) — 集中式主控

### 定位：所有事情一台搞定

NUC性能够强，不需要分布式部署。所有东西插一台机器上。

### 单个NUC负责全部

| 模块 | 实现方式 |
|:--|:--|
| HomeAssistant | Docker跑，管理所有设备 |
| MQTT Broker（Mosquitto） | Docker跑，设备通信总线 |
| Zigbee Coordinator | USB插CC2652P，管全屋Zigbee设备 |
| 红外发射器 | USB红外棒/USB转串口+IR模块 |
| 本地语音采集 | USB麦克风阵列 |
| 音频输出 | HDMI音频或USB声卡 |
| 摄像头 | USB摄像头 x N |
| 本地文件服务 | Samba/NFS，存监控录像和日志 |
| Hermes实例 | 轻量agent，跑调度M和家居域花 |

### 部署方式

```
         ┌──── NUC（全功能）──────────────┐
         │                                │
         │  Docker:                       │
         │  ├── HomeAssistant             │
         │  ├── Mosquitto (MQTT)          │
         │  ├── Zigbee2MQTT               │
         │  └── Hermes agent（轻量）       │
         │                                │
         │  USB直插:                      │
         │  ├── CC2652P (Zigbee天线)      │
         │  ├── USB摄像头 x2-3            │
         │  ├── USB麦克风                 │
         │  └── 红外发射棒                │
         │                                │
         │  GPIO/i2c:                     │
         │  └── (可选) 温湿度传感器        │
         └────────────────────────────────┘
```

### NUC vs 树莓派：选哪个

| 维度 | NUC | 树莓派5 |
|:--|:--:|:--:|
| CPU | i3/i5 (4-8核) | ARM Cortex-A76 (4核) |
| RAM | 8-32G | 8G max |
| 磁盘 | NVMe SSD 256G+ | SD卡（易损） |
| USB | 4-6个 | 2个USB 3.0 |
| 功耗 | 15-30W | 5-8W |
| 价格 | ¥1500-3000 | ¥500-700 |
| Docker性能 | ✅ 完全 | ⚠️ ARM兼容性 |
| 多摄像头 | ✅ 轻松 | ❌ USB带宽有限 |
| 24h运行 | ✅ | ✅ |
| 扩展性 | ✅ 多USB+PCIe | ⚠️ GPIO但USB少 |

### 我的建议：起步用NUC

- 你马上入职有收入了，¥1500-2000不是大问题
- 一台NUC干所有事，不用折腾多节点
- Docker兼容性好，HomeAssistant随便跑
- USB口多，插摄像头/Zigbee/红外/麦克风都不打架

**树莓派的场景**是当你需要扩展到多房间时——NUC做主控，每个房间加树莓派做节点。

## 跟你现有腾讯云的分工

```
                      ┌─────────────────────┐
                      │  腾讯云（Begonia）    │
                      │  · 24h在线值守       │
                      │  · 飞书对话入口      │
                      │  · API调度（DeepSeek）│
                      │  · 数字域花（搜索/    │
                      │    批判/职场等）      │
                      └────────┬────────────┘
                               │ 云端API
                               ▼
                      ┌─────────────────────┐
                      │  本地（NUC/树莓派）   │
                      │  · 设备控制           │
                      │  · 传感器采集         │
                      │  · 实时响应（<100ms） │
                      │  · 家居域花（安防/    │
                      │    环境/急救/场景等）  │
                      └─────────────────────┘
```

腾讯云做**大脑**（推理），本地做**手脚**（执行）。你现在腾讯云上跑的那套Soul Garden完全不用改——只是多了一个本地层来连物理世界 😏
