## 二、软件架构

```
┌─────────────────────────────────────────┐
│           腾讯云（Begonia）               │
│  · 飞书对话入口                          │
│  · DeepSeek API 调度                     │
│  · 数字域花（搜索/批判/职场等）           │
└──────────────┬──────────────────────────┘
               │ API
               ▼
┌─────────────────────────────────────────┐
│         NUC / 旧笔记本（本地）            │
│                                          │
│  Docker容器:                             │
│  ├── HomeAssistant    — 设备统一管理      │
│  ├── Mosquitto        — MQTT消息总线     │
│  ├── Zigbee2MQTT      — Zigbee设备桥接   │
│  └── Hermes agent     — 轻量家居域花     │
│                                          │
│  USB直插:                                │
│  ├── CC2652P           — Zigbee天线      │
│  ├── USB摄像头         — 视觉采集        │
│  └── 红外发射棒        — 控制老设备       │
└─────────────────────────────────────────┘
```

## 三、落地阶段

### Phase 0：准备（入职前，现在~1个月）
- [ ] 确认住处（锦州宿舍/租房？决定了硬件怎么装）
- [ ] 盘点闲置旧笔记本（有就不用买NUC）
- [ ] 确认预算（起步¥300-450买传感器就够了）

### Phase 1：基础平台（入职后第一周）
- [ ] NUC/旧笔记本装 Ubuntu Server 22.04
- [ ] 装 Docker + Docker Compose
- [ ] 拉 HomeAssistant 容器
- [ ] 拉 Mosquitto MQTT 容器
- [ ] 配置基础网络（固定IP/WiFi）
- [ ] 测试：HA Web界面能打开

### Phase 2：Zigbee设备接入（Phase 1后1-2天）
- [ ] USB插CC2652P → Docker拉Zigbee2MQTT
- [ ] 配对温湿度传感器
- [ ] 配对人体传感器
- [ ] 配对门窗传感器
- [ ] 测试：HA里能看到设备数据

### Phase 3：本地agent接入（Phase 2后1天）
- [ ] NUC上装Hermes agent（轻量版）
- [ ] 写Soul Garden家居域花的SOUL.md
- [ ] 打通腾讯云Begonia ↔ NUC本地链路
- [ ] 测试：你在飞书说"客厅温度多少"，Begonia -> NUC -> HA -> 回你

### Phase 4：扩展（按需）
- [ ] 接智能插座 → 控制灯具/电器
- [ ] 接红外发射棒 → 控制空调/电视
- [ ] 接USB摄像头 → Frigate人形检测
- [ ] 加更多传感器（烟雾/燃气/漏水/光照）
- [ ] 联动自动化（人走灯灭/温度到了关空调）
