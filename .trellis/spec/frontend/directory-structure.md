# Directory Structure

> How the wiki project is organized.

---

## Overview

This is a content-focused Starlight wiki site (Astro + Starlight). No custom UI components — all content is markdown under `src/content/docs/`.

---

## Directory Layout

```
wiki/
├── src/
│   ├── content/
│   │   └── docs/              # All wiki content (markdown)
│   │       ├── ai-daily/       # 每日AI云组会简报 (auto-generated)
│   │       ├── amaranth/       # Amaranth 相关
│   │       ├── blog/           # 博客文章
│   │       ├── freebies/       # 白嫖指南
│   │       ├── hermes/         # Hermes Agent 文档
│   │       ├── hermes-toolkit/ # Hermes 工具集
│   │       ├── notes/          # 各种笔记、参考
│   │       ├── projects/       # 项目文档
│   │       ├── skill-share/    # Skill 分享
│   │       ├── index.md        # 首页
│   │       └── ...             # 其他内容
│   ├── content.config.ts       # Starlight 内容配置
│   ├── env.d.ts                # TypeScript 环境声明
│   └── styles/
│       └── custom.css          # 自定义样式
├── public/
│   ├── amaranth-photo.jpg      # 头像/品牌图片
│   └── favicon.svg             # 站点图标
├── dist/                       # 构建产物 (gitignored)
├── .github/
│   └── workflows/
│       └── deploy.yml          # Cloudflare Pages 自动部署
├── astro.config.mjs            # Astro + Starlight 配置
├── package.json
└── AGENTS.md                   # Codex / Trellis 入口
```

---

## Content Organization

- **One directory per category** — mirror the sidebar structure in astro.config.mjs
- **Flat files** — no nesting beyond one level (except hermes/ which has many pages)
- **index.md** — each directory gets an index.md as the category landing page

---

## Naming Conventions

| Type | Convention | Example |
|------|-----------|---------|
| Content files | `kebab-case.md` | `gpu-training-pitfalls.md` |
| Directories | `kebab-case` | `ai-daily/`, `hermes-toolkit/` |
| Assets | `kebab-case.ext` | `amaranth-photo.jpg` |
| Config files | camelCase or kebab | `content.config.ts`, `astro.config.mjs` |

---

## Auto-generated Content

- `ai-daily/YYYY-MM-DD.md` — daily briefing, generated by cron job
- These files are committed to git (they're part of the wiki)
