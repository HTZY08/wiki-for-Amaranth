# AI云组会 2026-07-17 星期五

## 🔥 今日热议

### 1. Kimi K3 正式发布：2.8T 开放权重模型登顶多项基准
**来源：** @Kimi_Moonshot, @LiorOnAI, @rauchg, @C_Barraud
**链接：** https://x.com/Kimi_Moonshot/status/2077830229968683203

月之暗面于 7 月 16 日晚正式发布 Kimi K3，这是一个 **2.8T 总参数、16/896 活跃专家的 LatentMoE 架构**开放权重模型。关键细节：
- **1M token 上下文窗口**，原生多模态
- **Kimi Delta Attention (KDA)**：百万 token 上下文中解码速度提升最高 6.3 倍
- **Attention Residuals**：训练效率提升 ~25%，额外成本 <2%
- 在 **SWE Marathon（42.0，领先 Opus 4.8 两分）**、**BrowseComp（91.2）**、**Automation Bench（30.8）** 多个基准上超越包括 Claude Fable 5 和 GPT-5.6 Sol 在内的闭源模型
- **开放权重将于 7 月 27 日前发布**，vLLM 首日即支持

@C_Barraud 指出发布窗口恰好对齐今天（7 月 17 日）在上海开幕的 **WAIC 2026**。@LiorOnAI 称其为"首个在 Fable/Sol 级别竞争的开放 3T 级模型"。这是中国团队首次在通用基准上同时超越 OpenAI 和 Anthropic 的旗舰模型。

### 2. GPT-5.6 Sol Ultra 攻克 50 年未解数学猜想
**来源：** @polynoamial, @kimmonismus, @littmath
**链接：** https://x.com/polynoamial/status/2075646048425431469

OpenAI 的 @polynoamial 宣布 GPT-5.6 Sol Ultra 成功证明了 **Cycle Double Cover Conjecture（圈双覆盖猜想）**——一个已悬而未决 50 年的图论猜想。使用了 64 个子 agent 并行推理，**在不到一小时内**生成完整 Lean 形式化证明。

@kimmonismus 确认这是 AI 首次独立解决此类长期开放的数学前沿问题（区别于 IMO 等竞赛题）。@littmath（数学家）表示"细节还在梳理，但很可能是正确的"。这是从"解竞赛题"到"做真研究"的质变。

### 3. xAI 开源 Grok Build：编码 Agent 的 Rust 化标准件
**来源：** @FurkanGozukara, @Marktechpost, @yagiznizipli
**链接：** https://x.com/FurkanGozukara/article/2077522879609004425

7 月 15 日，xAI 以 **Apache 2.0** 协议开源了 **Grok Build**——其终端编码 agent 的底层 Rust 框架。注意：**开源的并非 Grok 4.5 模型本身**（模型仍在私有 beta 阶段），而是其 agent 运行时、工具层和 TUI。关键内容：
- 99.6% Rust，位于 `xai-org/grok-build`
- 核心 crate `xai-grok-shell`：agent 运行时 + leader/stdio/headless 三入口
- 支持任意模型（通过 `~/.grok/config.toml` 声明）
- Grok 4.5 模型在 FrontierSWE 编码基准上接近榜首

@Marktechpost 评价："开源的只是 '脚手架'，但你用任何模型都能搭上去——这是一个'模型无关的 agent 标准件'。"

### 4. Inkling：Mira Murati 新公司 Thinking Machines 发布首个开放权重模型
**来源：** @miramurati, @mark_k
**链接：** https://x.com/miramurati/status/2077455974743593100

Mira Murati（前 OpenAI CTO）创办的 Thinking Machines 发布了 **Inkling**——一个 **975B 参数 MoE（41B 活跃）**、**1M token 上下文**的原生多模态（文本/图像/音频/视频）开放权重模型。
- 在 45T token 上预训练
- SWE-bench Verified **77.6%**，AIME 2026 **97.1%**
- 支持**可控思考强度**（thinking effort）
- 完整权重已在 HuggingFace 发布，可通过 Tinker 平台微调
- 演示了模型自我编写并运行微调任务的自动化流程

这是继 Mistral 和 DeepSeek 之后，**又一家有影响力的大厂前高管团队押注开放权重路线**。

### 5. RoboTTT：NVIDIA 开源机器人长程运动模型
**来源：** @DrJimFan, @keshigeyan
**链接：** https://x.com/keshigeyan

NVIDIA GEAR Lab 开源了 **RoboTTT**（基于 Test-Time Training 的机器人策略模型），原生支持 **8,000 时间步**（约 5 分钟）的机器人运动上下文，推理成本不变。传统机器人策略通常只能处理 <0.1 秒的瞬间动作——这是机器人"肌肉记忆"量级的飞跃，让机器人理解并执行数分钟的连续操作序列。

## 💡 技术洞见

**1. "循环工程"（Loop Engineering）成为新共识**
从 @AndrewYNg、@bcherny 到 Claude Code 团队——"循环工程"正取代提示工程成为主流范式。核心思想：不是让 AI 一次回答，而是设计一个包含自我纠正、多步迭代的**循环**。Claude Code 的 `/loops` 功能、OpenAI 的 "Subagent" 多 agent 协调、Grok Build 的 agent harness 本质上都是同一种设计模式的不同实现。**你的工作不再是写提示词，而是构建系统。**

**2. 开放权重模型的"里程碑周"**
@ylecun、@levie、@ClementDelangue 等多位 KOL 指出：Kimi K3 + Inkling 在同一周发布，加上 DeepSeek V3 和 Mistral Large 的持续迭代，开放权重模型首次在**基准覆盖范围**（编码/推理/多模态/agent）上齐平甚至超越闭源模型。这不再是个别模型偶发表现，而是一个结构性趋势。

**3. AI 情感与交互界面的质变**
@kaifulee 转发了一线研究：人们与 AI 进行浪漫对话——"这是真爱还是完美模仿？"。@sama 观察到与 ChatGPT 的交互已以语音为主（超过打字）。两者共同指向：随着交互自然化，AI 从"工具"向"伙伴"转变，情感因素将主导产品设计方向。
