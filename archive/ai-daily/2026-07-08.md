### 2. "不要再 prompt agent 了——设计 loop 来替你 prompt"

这是本周 AI 工程圈最响的声音。Boris Cherny（Claude Code 负责人 @bcherny）在多个场合反复强调的核心理念：

> "You shouldn't be prompting coding agents anymore. You should be designing loops that prompt your agents."

实施效果：某团队从 20-30% agent 成功率跃升到 80%。

**Loop Engineering** 正在成为 2026 年 AI 工程的定义性技能：
- @addyosmani 撰文：Loop engineering 是"用系统替代人作为 prompter"
- @hellonehha：Loop 是"控制 agent 何时 prompt、如何 check、何时 route、何时 stop 的闭环"
- @omarsar0：从"prompt agent"到"design loops that prompt for you"的范式转移
- @steipete：已经在每月固定提醒"stop prompting, start looping"

**Karpathy 在 Sequoia AI Ascent 2026** 上正式提出 **"Agentic Engineering"** 概念——agentic engineering 是区分 production-grade agent work 和 vibe coding 的学科。去年他提出了"vibe coding"（降低编码门槛），今年他说"从未感觉自己作为程序员如此落后"——因为门槛在提高，agent 在接手执行层，人类负责判断和架构。

### 3. Claude Sonnet 5 — 头版不是 benchmark，是价格

Anthropic 上周（6月30日）将 Claude Sonnet 5 设为 Free/Pro 用户默认模型。Roupen Odabashian 的评论一针见血：

> "过去一年 agent 的瓶颈不是能力，是经济性。一个需要 40 次模型调用的工作流在 frontier 价格下是 demo，在十分之一价格下是产品。"

- **促销价 $2/$10**（到 8月31日），之后 $3/$15
- Artificial Analysis Intelligence Index 上得分 53（高于 Opus 但低于最新旗舰）
- 但用户反馈：实际 agent 任务的 cost-performance 比才是关键——@TimDaugs 实测 Sonnet 5 生成静态图花费 $0.36，Opus 4.8 生成可用动画只需 $0.18

**核心判断**：模型竞争的维度正在从"谁的 benchmark 更高"转向"谁能让 agent 工作流在合理成本下跑完"。Sonnet 5 的定位准确踩中这个转变。

📎 [@RoupenMD](https://x.com/RoupenMD/status/2074509464594743752) | [@ArtificialAnlys](https://x.com/ArtificialAnlys/status/2072062592923930666) | [@NeoAIForecast](https://x.com/NeoAIForecast/article/2072251810379891149) | [@TimDaugs](https://x.com/TimDaugs)

### 4. MCP 2026-07-28 RC 发布 — 协议走向无状态

MCP 发布了迄今为止最大的更新。核心变化是 **protocol 彻底 stateless**：

- 无 handshake、无 session id、任意请求可打到任意 server 实例
- MCP Apps 和 Tasks 成为一等公民
- 形式化 deprecation policy——"不用再这样干一次了"
- Auth 安全性加固

这对 agent 基础设施的影响深远：stateless MCP = 可以水平扩展的 agent 工具层，不再需要 sticky session 或 connection 管理。@krispuckett 从设计师角度的解读尤其值得关注。
